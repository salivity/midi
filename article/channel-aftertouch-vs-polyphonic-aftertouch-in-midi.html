Channel Aftertouch vs Polyphonic Aftertouch in MIDI

MIDI aftertouch allows musicians to modulate sound parameters by varying key pressure after the initial strike. At the MIDI message level, the critical functional difference between channel aftertouch (often called channel pressure) and polyphonic aftertouch (key pressure) lies in their data byte structure, targeting capability, and generated bandwidth: channel aftertouch applies a single global pressure value across an entire MIDI channel using a 2-byte message, whereas polyphonic aftertouch transmits per-note pressure values using a 3-byte message that specifies both the individual note number and its unique pressure level.

Channel Aftertouch (Channel Pressure)

Channel aftertouch is designed to detect the average or maximum pressure exerted across a keyboard bed and apply that change to all active notes on that channel simultaneously.

  • Status Byte: 0xDn (where D is the command identifier and n corresponds to the MIDI channel from 0 to 15, representing channels 1 through 16).
  • Data Byte 1: Pressure value (ranging from 0x00 to 0x7F, or 0 to 127).
  • Total Message Size: 2 bytes.

Because the message lacks a note-number parameter, the receiving synthesizer cannot isolate which key triggered the pressure change. When a player presses down harder on one key in a held chord, the synth’s global modulation routing (such as filter cutoff, pitch vibrato, or volume) changes uniformly for every sounding note. Hardware implementations typically use a single conductive ribbon or force-sensing strip running underneath the entire keybed, making channel aftertouch cost-effective and light on MIDI bandwidth.

Polyphonic Aftertouch (Key Pressure)

Polyphonic aftertouch provides independent expression for every individual key, enabling a player to modulate one note while leaving other sustained notes unaffected.

  • Status Byte: 0xAn (where A is the command identifier and n corresponds to the MIDI channel).
  • Data Byte 1: Note number (0x00 to 0x7F, representing MIDI notes 0 to 127).
  • Data Byte 2: Pressure value (0x00 to 0x7F, representing pressure from 0 to 127).
  • Total Message Size: 3 bytes.

Because the message structure explicitly includes the note number, receiving sound engines can direct continuous control data to the discrete voice architecture handling that specific pitch. For example, a player holding a three-note chord can physically lean into the middle note to introduce vibrato to that voice alone.

Key Technical Differences

  • Message Structure: Channel aftertouch requires 2 bytes (Status, Value), while polyphonic aftertouch requires 3 bytes (Status, Note Number, Value).
  • Bandwidth Usage: Channel aftertouch generates a single stream of 2-byte messages. Polyphonic aftertouch generates multiple parallel streams of 3-byte messages as each finger moves independently, significantly increasing the data density over a standard 31.25 kbaud 5-pin DIN connection.
  • Hardware & Engine Requirements: Polyphonic aftertouch demands individual physical sensors beneath every key and a synthesizer architecture capable of per-voice parameter routing, whereas channel aftertouch functions with a single master sensor and global modulation busses.
