Relative Encoding Modes for Endless MIDI Encoders

Endless MIDI rotary encoders eliminate parameter jumping by transmitting relative changes (increments and decrements) rather than fixed absolute values between 0 and 127. Because standard MIDI Control Change (CC) messages lack a universal relative standard, hardware manufacturers and Digital Audio Workstations (DAWs) rely on a handful of established encoding formats. This article covers the primary relative encoding modes used in modern MIDI devices, including Sign-Magnitude, 2's Complement, Binary Offset, and Single-Value stepping.

Why Endless Encoders Use Relative Modes

Standard potentiometers send an absolute value based on their physical angle. If a software control is set to 100 and an absolute knob currently resting at 20 is moved, the software value instantly snaps to 20. Endless encoders prevent this issue by transmitting how far and in which direction the knob has turned, allowing software to smoothly adjust values from their existing positions.

2's Complement (Relative 1)

In 2's Complement mode, values starting from 1 represent clockwise (positive) rotation, while values counting down from 127 represent counterclockwise (negative) rotation.

  • Clockwise (Increment): 1 (+1 step), 2 (+2 steps), 3 (+3 steps), etc.
  • Counterclockwise (Decrement): 127 (-1 step), 126 (-2 steps), 125 (-3 steps), etc.

Because it mimics standard binary two's complement notation in a 7-bit system, this format is widely supported and commonly serves as the default relative mode in DAWs like Ableton Live, Bitwig, and Cockos Reaper (often labeled "Relative 1").

Binary Offset (Relative 2)

Binary Offset centers the resting point at value 64. Movement above 64 indicates positive adjustment, while movement below 64 indicates negative adjustment.

  • Clockwise (Increment): 65 (+1 step), 66 (+2 steps), 67 (+3 steps), etc.
  • Counterclockwise (Decrement): 63 (-1 step), 62 (-2 steps), 61 (-3 steps), etc.

This format provides a simple arithmetic approach where the offset (value - 64) directly yields the directional speed and step count.

Sign-Magnitude (Relative 3)

Sign-Magnitude reserves one bit to define direction, while the remaining bits indicate the magnitude (number of steps or acceleration speed). In MIDI's 7-bit architecture, bit 6 (value 64) acts as the sign flag:

  • Clockwise (Increment, Bit 6 = 0): 1 (+1 step), 2 (+2 steps), 3 (+3 steps), up to 63.
  • Counterclockwise (Decrement, Bit 6 = 1): 65 (-1 step, calculated as 64 + 1), 66 (-2 steps), 67 (-3 steps), etc.

This mode is standard on equipment from manufacturers such as Arturia and Native Instruments, and is frequently labeled "Relative 3" or "Signed Bit" in MIDI configuration utilities.

Single-Value / Fixed Increment-Decrement

Some hardware designs do not transmit variable velocity or step sizes. Instead, they output single static values for movement in either direction regardless of rotational speed:

  • Clockwise: Transmits a static value, typically 1 or 127.
  • Counterclockwise: Transmits a static value, typically 127 or 0.

The DAW detects the specific value sent to determine whether to increment or decrement the targeted parameter by a fixed amount.

Matching Hardware to Software

For an endless encoder to function properly, the output mode chosen in the hardware's editor must match the relative decoding mode selected inside the receiving DAW or plugin. If the modes are mismatched, common issues occur: turning the knob counterclockwise may jump the value to maximum, or turning clockwise may cause the parameter to flutter back and forth instead of moving smoothly.
