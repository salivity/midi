MIDI CC 84 Portamento Control Explained

MIDI Continuous Controller 84 (CC 84), officially designated as Portamento Control, is a specialized MIDI message designed to set the starting pitch of a glide rather than just its speed or state. While conventional portamento typically glides from whatever note is currently sounding to the next one played, CC 84 allows a composer or sequencer to explicitly define an exact source note number. This article breaks down the technical function of CC 84, explains how its data value dictates the glide's origin pitch, and outlines how it differs from standard portamento controls.

The Purpose of MIDI CC 84

In standard MIDI implementations, portamento is managed through two primary controllers:

  • CC 65 (Portamento On/Off): Enables or disables glide functionality.
  • CC 5 (Portamento Time): Governs how long the transition between pitches takes.

Under this standard behavior, a glide requires a currently active or previously sustained note to establish the starting pitch. MIDI CC 84 eliminates this requirement by providing explicit control over the glide's origin. Its core purpose is to allow a sequencer or controller to trigger a slide into a new note from a completely independent, user-defined pitch without physically playing or sustaining the initial note first.

How CC 84 Designates the Source Key

Standard MIDI control change messages consist of a status byte, a controller number (84 in this case), and a data value ranging from 0 to 127.

When CC 84 is transmitted, its 0–127 value is interpreted as a standard MIDI note number:

  • Value 0 corresponds to C-1.
  • Value 60 corresponds to Middle C (C4).
  • Value 127 corresponds to G9.

Instead of modulating an effect parameter, the value sent via CC 84 directly names the note that will serve as the launchpad for the portamento effect.

The Execution Sequence

For CC 84 to take effect, the MIDI messages must be sent in a specific order:

  1. CC 84 Transmission: A CC 84 message is sent with a specific value (e.g., CC 84, Value 48 [C3]). This pre-loads note C3 into the synthesizer's portamento buffer as the source pitch.
  2. Note-On Message: Immediately following the CC 84 message, a standard Note-On command is triggered for the target pitch (e.g., Note-On 60 [C4]).
  3. Synthesis Engine Response: Rather than sounding C4 immediately or sliding from the previous key pressed, the synthesizer instantly begins generating sound at C3 and glides upward to C4 at the speed defined by CC 5.

Once the target note is reached, the effect is consumed. Subsequent Note-On messages without a preceding CC 84 message will either behave normally (sounding immediately or gliding from the previously held key if CC 65 is enabled) depending on the synth's architecture.

Common Use Cases

  • Isolated Pitch Slides: Creating pitch glides into notes that start after a period of silence, where traditional legato-based portamento would not trigger.
  • Complex Basslines and Lead Solos: Programming realistic slides for instruments like fretless bass, synth leads, or pedal steel guitars, where the attack should emulate sliding up or down from an un-struck fret or position.
  • Deterministic Sequencing: Ensuring consistent playback in studio environments by explicitly writing the starting note into the MIDI data, preventing random slide behavior caused by differing note overlaps.

Note: Hardware and software synthesizer support for CC 84 varies. While it is part of the official MIDI standard, developers must explicitly program their synthesis engines to read and respond to CC 84 source note values.
