Mac IAC Driver Explained: How to Route Internal MIDI

The Inter-Application Communication (IAC) driver is a native macOS utility that allows digital audio workstations (DAWs), sequencers, and music utilities to transmit MIDI data directly to one another on the same computer without external cables or hardware interfaces. This article explains what the IAC driver is, how it utilizes Apple's CoreMIDI framework to create virtual signal paths, how to enable and configure it, and key technical considerations such as latency and feedback loops.

What Is the IAC Driver?

Built directly into macOS via the Audio MIDI Setup utility, the IAC driver serves as a software-based MIDI loopback device. In a standard hardware setup, sending MIDI from one device to another requires physical 5-pin DIN or USB cables connected to a MIDI interface. The IAC driver replicates this behavior entirely within the operating system. It creates virtual input and output ports—referred to as "buses"—that any MIDI-compatible macOS application can recognize as standard hardware ports.

How Internal MIDI Routing Works on Apple Platforms

The IAC driver relies on Apple’s system-level CoreMIDI architecture:

  1. System Registration: When enabled, the IAC driver registers as an active MIDI endpoint in macOS. The system presents its configured buses to the CoreMIDI server as available sources (transmitters) and destinations (receivers).
  2. Inter-Process Data Transfer: When Application A sends a MIDI message (such as a Note On, Control Change, or Clock event) to an IAC bus, the CoreMIDI server captures this data packet. Instead of routing the packet to a USB driver or external device, CoreMIDI holds the data in system memory and immediately dispatches it to any application registered to listen to that same IAC bus.
  3. Receipt and Processing: Application B, configured to monitor the corresponding IAC bus as an input, receives the MIDI messages as if they arrived from an external MIDI controller or hardware sequencer.

Because the data never leaves system memory, the transmission occurs with near-zero latency, avoiding the timing jitter and physical transmission delays associated with USB polling rates and hardware buffers.

Configuring the IAC Driver

To configure and enable the IAC driver in macOS:

  1. Launch Audio MIDI Setup (located in /Applications/Utilities).
  2. Go to the menu bar and select Window > Show MIDI Studio.
  3. Locate the IAC Driver icon (often grayed out by default) and double-click it to open its properties window.
  4. Check the box labeled Device is online.
  5. Under the Ports section, review or add buses by clicking the + button. You can rename these buses (e.g., "IAC Bus 1", "Clock Bus") for clearer identification in your software.
  6. Click Apply.

Once activated, these buses appear as standard MIDI Inputs and Outputs across all running software capable of CoreMIDI communication.

Common Use Cases

  • Routing Algorithmic Sequencers: Streaming real-time MIDI data generated in programming environments like Max/MSP, Pure Data, or SuperCollider directly into instruments hosted within DAWs like Logic Pro, Ableton Live, or Pro Tools.
  • Master Clock Synchronization: Sending MIDI Clock or MIDI Time Code (MTC) from one standalone application to slave another project running concurrently.
  • Bridging Standalone Synths and DAWs: Recording the MIDI performance of standalone soft synths or arpeggiators directly into a DAW’s timeline for editing.

Critical Considerations: Avoiding MIDI Feedback Loops

The most common issue when working with the IAC driver is a MIDI feedback loop. This occurs when an application receives MIDI from an IAC bus and simultaneously echoes or routes that same MIDI back out to the same bus (often caused by selecting "All MIDI Inputs" on a track while routing its output back to the IAC bus). This creates an infinite, processor-choking loop of duplicated messages that can freeze your audio applications.

To prevent feedback loops:

  • Explicitly assign specific MIDI inputs to tracks rather than using generic "All Inputs" settings.
  • Disable software MIDI thru functions for the specific IAC bus in use unless strictly required by your signal chain.
