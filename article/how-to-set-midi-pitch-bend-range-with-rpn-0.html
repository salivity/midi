How to Set MIDI Pitch Bend Range with RPN 0

This guide explains how to reconfigure the pitch bend wheel sensitivity on any MIDI-compatible hardware instrument using Registered Parameter Number (RPN) 0. By transmitting a standard sequence of MIDI Continuous Controller (CC) messages, you can define the exact semitone and cent range that the hardware wheel spans without having to navigate deep hardware configuration menus.

Understanding the RPN 0 Message Structure

RPN messages require a standardized sequence of MIDI CC commands to target the correct setting and adjust its value. Pitch Bend Sensitivity is designated globally in the MIDI specification as RPN 0. Modifying it requires targeting the parameter via CC 101 and CC 100, entering the desired range value using CC 6 (and optionally CC 38), and finally resetting the parameter selection to avoid unintended edits.

Step 1: Select RPN 0

To tell the receiving instrument that you want to adjust pitch bend sensitivity, send the following two messages on the target MIDI channel:

  1. CC 101 (RPN MSB): Set to value 0
  2. CC 100 (RPN LSB): Set to value 0

Once these two messages are received, the synthesizer or sound module enters an edit state for Pitch Bend Range.

Step 2: Set the Semitone Range (Data Entry MSB)

The coarse pitch bend range is measured in semitones and is controlled via Data Entry MSB:

  • CC 6 (Data Entry MSB): Set to your desired semitone interval (range 0 to 127).

Common Values:

  • Value 2 = ±2 semitones (1 whole step; the standard default for most instruments)
  • Value 7 = ±7 semitones (a perfect fifth)
  • Value 12 = ±12 semitones (1 full octave)
  • Value 24 = ±24 semitones (2 full octaves)

Step 3: Optional Fine-Tuning in Cents (Data Entry LSB)

If you require microtonal bends or fine calibration, you can transmit a fractional range adjustment:

  • CC 38 (Data Entry LSB): Set to the desired fractional value in cents (range 0 to 127).

For standard tuning in whole semitones, set CC 38 to 0 or omit this message entirely.

Step 4: Deselect the Parameter (RPN Null)

To prevent subsequent CC 6 or CC 38 messages from accidentally modifying the pitch bend sensitivity during a performance, close the RPN session by setting the controller to the "Null" state:

  1. CC 101 (RPN MSB): Set to value 127
  2. CC 100 (RPN LSB): Set to value 127

Example Message Sequence

To configure a hardware synth to a ±1 octave (12 semitones) pitch bend range on MIDI Channel 1, send the following consecutive event list:

Byte Order Message Type Control Number Value Function
1 Control Change CC 101 0 Select RPN MSB (0)
2 Control Change CC 100 0 Select RPN LSB (0)
3 Control Change CC 6 12 Set range to 12 semitones
4 Control Change CC 38 0 Set fine-tune to 0 cents
5 Control Change CC 101 127 Reset RPN MSB (Null)
6 Control Change CC 100 127 Reset RPN LSB (Null)

This sequence can be programmed into an initialization track within a DAW, sent from an external hardware MIDI sequencer, or assigned to macro buttons on advanced master controllers.
