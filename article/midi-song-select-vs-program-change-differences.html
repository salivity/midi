MIDI Song Select vs Program Change Differences

While both MIDI Song Select and MIDI Program Change messages are used to recall stored data in hardware and software instruments, they operate at fundamentally different levels of the MIDI protocol. A Program Change message is a Channel Voice message designed to switch instrument presets or sound patches on a single specific MIDI channel. In contrast, a Song Select message is a System Common message intended to load an entire sequence, song, or arrangement on a multi-track sequencer or drum machine across the whole system.

What Is a MIDI Program Change Message?

A MIDI Program Change message belongs to the Channel Voice category. It is transmitted on a specific MIDI channel (channels 1 through 16), meaning it only alters the settings of the device or track configured to listen to that specific channel.

  • Primary Function: It switches the active sound, preset, or instrument patch (such as changing an electric piano to a synthesizer lead).
  • Data Structure: The message consists of a status byte (0xCn, where n represents the channel number) followed by a single data byte ranging from 0 to 127.
  • Expansion: Because a single byte only allows for 128 patch options, Program Change is frequently paired with Bank Select messages (Control Change 0 and Control Change 32) to access thousands of presets.

What Is a MIDI Song Select Message?

A MIDI Song Select message belongs to the System Common category. It is not tied to a specific MIDI channel and is broadcast globally to all connected devices on a MIDI bus.

  • Primary Function: It instructs a playback device, such as a hardware sequencer, drum machine, or backing-track player, to load a specific song or pattern from its internal memory.
  • Data Structure: The status byte for Song Select is fixed at 0xF3, followed by one data byte representing the song number (0 to 127).
  • Workflow Role: It typically prepares a sequencer before playback begins. Once the song is selected via this message, a separate MIDI Start message (0xFA) is sent to begin playback.

Key Differences at a Glance

  • Message Category: Program Change is a Channel Voice message (channel-specific); Song Select is a System Common message (global/system-wide).
  • Target Destination: Program Change targets sound generators, synthesizers, and effects processors; Song Select targets sequencers, drum machines, and media players.
  • Intended Result: Program Change alters the sonic timbre or instrument patch; Song Select selects an entire musical piece, pattern, or MIDI sequence.
  • Performance Context: Program Change is often used during a song to alter sounds dynamically; Song Select is generally sent between songs to prepare the playback engine for the next performance.
