MIDI CC 0 and CC 32 Bank Select Explained

This article explains how MIDI Continuous Controller (CC) 0 and CC 32 work together as a two-byte messaging system to overcome standard patch limitations. Standard MIDI Program Change messages only allow access to 128 sound presets, but by combining CC 0 as the Most Significant Byte (MSB) and CC 32 as the Least Significant Byte (LSB), MIDI devices can address up to 16,384 individual sound banks, each containing its own set of 128 programs.

The Need for Bank Select

The original MIDI 1.0 specification relies on a single 7-bit data byte for Program Change messages, limiting direct patch selection to values between 0 and 127. As synthesizers, samplers, and sound modules expanded to host thousands of presets, a mechanism was needed to switch between larger groups of sounds, known as banks. The MIDI Manufacturers Association solved this by designating two standard Control Change messages to create a 14-bit Bank Select command: CC 0 and CC 32.

The Role of CC 0 (MSB) and CC 32 (LSB)

Because standard MIDI data bytes are restricted to 7 bits (values from 0 to 127) to avoid conflict with MIDI status bytes, a single CC message cannot represent large numbers. To circumvent this, the Bank Select command is split into two halves:

  • CC 0 (Bank Select MSB): Acts as the "coarse" adjustment, representing the Most Significant Byte. It holds the upper 7 bits of the 14-bit bank number.
  • CC 32 (Bank Select LSB): Acts as the "fine" adjustment, representing the Least Significant Byte. It holds the lower 7 bits of the 14-bit bank number.

When combined, these two 7-bit values form a single 14-bit integer, providing \(128 \times 128 = 16,384\) potential bank addresses.

Calculating the Bank Number

A receiving device reconstructs the complete bank number by multiplying the CC 0 value by 128 and adding the CC 32 value:

\[\text{Bank Number} = (\text{CC } 0 \times 128) + \text{CC } 32\]

For example:

  • To select Bank 0: Send CC 0 with a value of 0, and CC 32 with a value of 0 (\((0 \times 128) + 0 = 0\)).
  • To select Bank 1: Send CC 0 with a value of 0, and CC 32 with a value of 1 (\((0 \times 128) + 1 = 1\)).
  • To select Bank 128: Send CC 0 with a value of 1, and CC 32 with a value of 0 (\((1 \times 128) + 0 = 128\)).
  • To select Bank 500: Send CC 0 with a value of 3, and CC 32 with a value of 116 (\((3 \times 128) + 116 = 500\)).

Transmission Sequence and Execution

Bank Select messages do not trigger an audible sound change on their own. Instead, they prepare the receiving MIDI device's memory for an upcoming patch change. The correct transmission order is:

  1. MIDI CC 0 (MSB): Sets the high-order bits of the bank address.
  2. MIDI CC 32 (LSB): Sets the low-order bits of the bank address.
  3. Program Change: Specifies which preset (0–127) within the newly designated bank to activate.

The receiving instrument holds the incoming CC 0 and CC 32 values in a staging buffer. Only when the subsequent Program Change message arrives does the instrument switch its engine to the targeted bank and preset simultaneously.

Device Implementation Differences

Not all hardware and software instruments utilize all 16,384 banks. Many simpler devices only listen to CC 0 (MSB) and ignore CC 32 (LSB), effectively limiting themselves to 128 banks. Conversely, some sound modules primarily use CC 32 while leaving CC 0 fixed at 0. Device implementation charts in the manufacturer's manual outline whether a specific instrument requires both bytes or only one to switch sound banks successfully.
