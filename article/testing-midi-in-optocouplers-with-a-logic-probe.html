Testing MIDI In Optocouplers With a Logic Probe

When a synthesizer fails to respond to incoming MIDI messages, a damaged optocoupler on the MIDI In circuit is one of the most common points of failure. Diagnosing this issue with a basic logic probe involves verifying incoming current pulses across the optocoupler’s input LED and checking for matching inverted digital pulses at the output pin while feeding active MIDI data into the instrument. This straightforward diagnostic procedure allows a technician to isolate a dead optocoupler without needing an oscilloscope.

1. Preparation and Signal Injection

Begin by connecting the logic probe's power leads to the synthesizer's internal logic rails—typically +5V (or +3.3V on modern units) and digital ground. Set the probe selector switches to TTL (or CMOS depending on the synthesizer logic level) and ensure the "Pulse" detection mode is enabled.

Connect a reliable MIDI controller, sequencer, or computer interface to the synthesizer's MIDI In port. Configure the sending device to transmit continuous MIDI data, such as a looping sequence, active MIDI Clock, or sweeping pitch bend messages. Continuous data is essential because static states will not reveal switching failures.

2. Identifying the Optocoupler

Locate the optocoupler IC adjacent to the 5-pin DIN or TRS MIDI In jack. Standard synthesizers typically use an 8-pin DIP or SMD optoisolator, such as the 6N138, 6N137, or PC900. Refer to the component datasheet to locate:

  • The input pins: Anode (pin 2 on a 6N138) and Cathode (pin 3).
  • The power pin: VCC (pin 8).
  • The output pin: Collector/Vout (pin 6 on a 6N138).
  • Ground: GND (pin 5).

3. Testing the Input Side

Touch the logic probe to the input pins connected to the MIDI DIN jack. A functional MIDI current loop switches the optocoupler's internal LED on and off.

  • While continuous MIDI data is sent, the logic probe should detect activity or pulse indications across these pins.
  • If there is no activity on the input side, the optocoupler is likely not receiving the signal. Inspect the MIDI DIN jack, the 220-ohm current-limiting resistors, the reverse-protection diode (often a 1N4148 parallel to the LED), or the cable itself before condemning the chip.

4. Testing the Output Side

Touch the logic probe tip to the optocoupler’s digital output pin. In a standard MIDI In circuit, this pin connects to the synthesizer’s UART or microprocessor and uses an external pull-up resistor tied to VCC.

  • Idle State: When no MIDI data is sent, the logic probe should register a steady HIGH state due to the pull-up resistor.
  • Active State: When continuous MIDI data is transmitted, the internal phototransistor turns on and pulls the pin to ground during each bit. The logic probe's LOW indicator and PULSE LED should flash rapidly, indicating digital transitions.

5. Interpreting the Fault

  • Stuck HIGH with Input Pulses: If input activity is present but the output pin remains solidly HIGH with zero pulse activity, the internal phototransistor has failed open, or the internal infrared LED has degraded. The optocoupler is defective.
  • Stuck LOW: If the output pin remains permanently LOW regardless of input, the output phototransistor has shorted to ground or the external pull-up resistor has failed.
  • Normal Pulsing: If the probe registers clear pulses on the output pin corresponding to input data, the optocoupler is fully functioning, and the fault lies downstream in the receiver UART, buffer IC, or processor.
