Understanding the MIDI Tuning Standard (MTS)

The MIDI Tuning Standard (MTS) is a protocol extension within the MIDI specification that allows electronic musical instruments to deviate from standard twelve-tone equal temperament (12-TET). By transmitting high-precision frequency data directly to hardware synthesizers via System Exclusive (SysEx) messages, MTS enables the implementation of alternative tunings, historical temperaments, and microtonal scales. This article details how MTS operates, the specific data formats it uses to redefine pitch intervals, and how compatible hardware processes these instructions to produce non-equal-tempered intervals.

The Limitations of Standard MIDI

Standard MIDI architecture links note numbers (0 to 127) to specific semitone values assuming a fixed 12-TET framework, anchored around A440 at note 69. In this default configuration, pitch bends can shift frequency globally across a channel, but individual intervals between discrete notes remain fixed at 100 cents. Consequently, realizing complex microtonal frameworks—such as just intonation, quarter-comma meantone, or arbitrary microtonal divisions (e.g., 19-TET, 31-TET)—traditionally required convoluted workarounds like assigning different voices to multiple MIDI channels with varying pitch bend offsets.

How MTS Redefines Hardware Frequency

The MIDI Tuning Standard bypasses 12-TET limitations by redefining the absolute frequency assigned to any MIDI note number. Rather than telling a synthesizer to shift a voice dynamically, MTS reprograms the internal tuning table of the hardware sound engine.

MTS expresses pitch using a 3-byte resolution per note:

  • Byte 1: Defines the base semitone (matching standard MIDI note values).
  • Bytes 2 and 3: Represent the fractional semitone offset down to a precision of 14 bits (16,384 discrete steps).

This provides a pitch resolution of roughly 0.0061 cents (calculated as \(100 \text{ cents} / 16,384\)), which is far below the threshold of human pitch discrimination. With this level of micro-tuning capability, hardware oscillators can match precise mathematical ratios (such as pure thirds or fifths in just intonation) without audible quantization artifacts.

Key MTS Message Formats

Hardware instruments receive MTS commands through specific SysEx formats, categorized by how they modify interval tables:

  1. Bulk Tuning Dump: Sends an entire scale definition consisting of frequency offsets for all 128 note numbers. This is typically loaded into a specific tuning bank or program location on the synthesizer prior to performance.
  2. Single Note Tuning Change (Real-Time or Non-Real-Time): Updates the frequency of a single note number instantaneously. This allows for adaptive or dynamic retuning, where scale intervals shift in real time based on the harmonic context of a performance.
  3. Scale/Octave Tuning Dump: Instead of defining all 128 individual keys, this format defines a repeatable 12-tone microtonal offset applied uniformly across every octave. This method requires significantly less data overhead and is ideal for repeating unequal scales, such as Pythagorean or Werckmeister temperaments.

Hardware Execution of Non-Equal Intervals

When an MTS-compliant synthesizer receives an MTS SysEx packet, its internal micro-controller parses the tuning values and stores them in a local lookup table. When a Note On event occurs:

  1. The synthesizer reads the incoming note number (e.g., note 60 for Middle C).
  2. Instead of routing the default 12-TET frequency (261.63 Hz) to the sound engine, it queries the MTS lookup table.
  3. The oscillator (whether a digital DSP phase accumulator or a digitally controlled analog oscillator) generates the specific target frequency dictated by the MTS offset.

By standardizing this process across manufacturers, MTS allows external software, master controllers, or sequencers to automate complex non-equal microtonality across a hardware studio setup simultaneously without requiring manual recalibration of each device.
