How a Piano Roll Editor Represents MIDI Data

A piano roll editor translates digital performance information into an intuitive, two-dimensional graphical interface. By mapping abstract MIDI messages onto a visual grid, it allows producers and composers to easily interpret and edit fundamental musical elements, including note pitch, note duration, strike velocity, and MIDI channel routing.

Pitch (Vertical Axis)

Pitch is mapped across the vertical Y-axis. On the far left of the editor sits a vertical depiction of a piano keyboard. Each horizontal lane on the grid corresponds to a specific semitone, ranging from low notes at the bottom to high notes at the top. When a MIDI note is recorded, it appears as a rectangular block placed directly in the lane that matches the key pressed.

Note Length (Horizontal Axis)

Note duration is displayed along the horizontal X-axis, which functions as a timeline divided into musical bars, beats, and sub-divisions. The horizontal start point of a note block indicates the exact moment the note is triggered (the MIDI Note On event). The width or length of the block visually represents how long the key is held until it is released (the MIDI Note Off event). Longer blocks correspond to longer sustained sounds.

Velocity (Color and Value Lanes)

Velocity, which measures how hard or fast a key was struck, is typically visualized in two ways:

  • Color and Brightness: Many modern editors use color gradients on the note blocks themselves. Lower velocities often appear lighter, cooler (such as blue or green), or less saturated, while high velocities appear darker, warmer (such as orange or red), or fully saturated.
  • Velocity Stalks/Lanes: Below the main grid, a dedicated lane displays vertical bars or "stalks" aligned with the start of each note. The height of the stalk directly reflects the MIDI velocity value on a scale from 0 to 127.

MIDI Channel Information

MIDI channel data determines which instrument or sound engine receives the performance messages. Editors typically represent channel assignments through color coding, where notes assigned to different channels are rendered in distinct colors within the same window. Alternatively, many digital audio workstations provide channel-selector dropdowns or track filters, allowing users to view, hide, or gray out inactive channels while highlighting the active MIDI stream.
