Roland GS MIDI Fallback Bank Selection Rules

The Roland General Standard (GS) MIDI specification extends General MIDI by introducing variation banks, allowing synthesizers to store hundreds of additional instrument sounds beyond the baseline 128 tones. To maintain backward compatibility and prevent silence during playback, GS defines a strict "bank fallback" mechanism that dictates which sound plays when a requested variation is missing from a sound module's ROM.

The Role of CC 0 and Program Change

Under the GS standard, selecting a specific instrument involves two MIDI messages:

  1. Control Change 0 (Bank Select MSB): Specifies the bank variation number (from 0 to 127). Control Change 32 (LSB) is largely ignored in basic GS implementation and fixed at 0.
  2. Program Change (PC): Specifies the tone number (from 1 to 128).

Bank 0 contains the "Capital Tones," which directly correspond to the standard General MIDI 1 instrument list (such as PC 1 for Acoustic Grand Piano). Banks 1 through 127 are designated for "Variation Tones," which are alternative versions of the Capital Tone (such as Detuned Piano, Honky-tonk, or Octave Piano).

The Bank Fallback Mechanism

When a GS MIDI sequence sends a CC 0 bank value to access a variation tone that the receiving sound module does not support, the module applies automatic bank fallback rules:

  • Fallback to Bank 0 (Capital Tone): If a sound module receives a request for a Program Change in a variation bank (e.g., Bank 8, Program 1) that it does not contain in memory, it ignores the missing variation and automatically plays the Capital Tone from Bank 0 with the same Program Change number (Bank 0, Program 1).
  • Seamless Audio Output: The note triggers without interruption, substituting the nearest generic equivalent rather than producing silence or returning a MIDI error.

Multi-Map Fallback Hierarchy

Later GS hardware, such as the Roland Sound Canvas SC-88, SC-88 Pro, and SC-8850, introduced backward-compatible sound "maps" (such as the SC-55 Map and native SC-88 Map). On these multi-layered synthesizers, the fallback procedure follows an expanded path:

  1. Exact Match Search: The module checks the selected map for the requested Bank (CC 0) and Program Change.
  2. Legacy Map Matching: If the variation does not exist in the higher-tier map, certain modules check corresponding locations in legacy maps.
  3. Capital Tone Substitution: If no variation exists in any layer of that specific bank address, the hardware defaults directly to the Capital Tone (Bank 0) of the selected map.

Through this predictable fallback routine, Roland ensured that advanced MIDI arrangements utilizing expanded patch libraries remained playable across entry-level and older hardware without requiring dedicated remap files.
