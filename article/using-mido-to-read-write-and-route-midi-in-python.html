Using Mido to Read, Write, and Route MIDI in Python

Mido is an open-source Python library that simplifies working with Musical Instrument Digital Interface (MIDI) data. It provides an intuitive, Pythonic interface for creating, reading, processing, and streaming MIDI messages, making it an essential tool for music production software, algorithmic composition, and hardware controller integration. By abstracting the low-level binary specifications of the MIDI standard and wrapping native platform drivers, Mido allows developers to handle both real-time communication and static MIDI files with minimal setup.

Understanding Mido Messages

At the core of Mido is the Message object, which encapsulates individual MIDI events such as note_on, note_off, control_change, and pitch bends. Instead of requiring manual byte manipulation, Mido allows you to define parameters as keyword arguments:

import mido

# Create a Note On event (Middle C, velocity 64)
msg = mido.Message('note_on', note=60, velocity=64, time=0.5)

# Inspect message attributes
print(msg.type)      # 'note_on'
print(msg.bytes())   # [144, 60, 64]

This abstraction ensures that data validation is performed automatically, preventing malformed MIDI packets from being generated.

Reading and Writing MIDI Files

Mido handles static files using the MidiFile and MidiTrack classes, supporting standard Type 0 and Type 1 files.

To write a sequence of notes to a file, you append messages to a track and save the file:

from mido import Message, MidiFile, MidiTrack

mid = MidiFile()
track = MidiTrack()
mid.tracks.append(track)

# Add events with delta times (in ticks)
track.append(Message('note_on', note=64, velocity=100, time=0))
track.append(Message('note_off', note=64, velocity=100, time=480))

mid.save('output.mid')

Reading a MIDI file is equally direct. You can iterate through all events sequentially, while Mido handles track synchronization and timing:

for msg in MidiFile('output.mid').play():
    # .play() generates real-time playback delays automatically
    print(msg)

Real-Time Routing and Hardware I/O

Mido interfaces with your operating system's audio subsystem through backends like python-rtmidi or PortMidi. This allows real-time sending and receiving of MIDI signals across external synthesizers, virtual ports, and DAWs.

To list available physical and virtual ports:

print(mido.get_input_names())
print(mido.get_output_names())

To read live input from a MIDI controller:

with mido.open_input('Keyboard Port Name') as inport:
    for msg in inport:
        print(f"Received: {msg}")

To route or modify messages dynamically, you can capture input from one port, alter its data (such as transposing pitch or scaling velocity), and forward it directly to an output port:

inport = mido.open_input('Keyboard')
outport = mido.open_output('Synthesizer')

for msg in inport:
    if msg.type == 'note_on':
        msg.note += 12  # Transpose up one octave
    outport.send(msg)

Through this unified API, Mido reduces complex MIDI protocol specifications into accessible, high-level Python code suitable for both standalone file processing and interactive audio applications.
