Live Performance MIDI Routing with Bome MIDI Translator

Bome MIDI Translator Pro is a versatile utility that acts as the central nervous system for complex stage setups. By running between physical controllers, synthesizers, and digital audio workstations (DAWs), it intercepts, modifies, and redirects MIDI data in real time. This article breaks down how the software manages intricate live performance routing through message transformation, dynamic logic, multi-device management, and virtual port redundancy.

Universal Message Transformation and Mapping

In a live environment, different hardware and software instruments often require distinct MIDI message formats. Bome MIDI Translator allows performers to convert any incoming MIDI message into virtually any other outgoing command:

  • Control Change (CC) to Keystrokes or Notes: A foot pedal can trigger software scenes or mute tracks by converting standard CC messages into computer keystrokes or discrete MIDI note-on events.
  • Value Scaling and Inversion: Performers can scale parameter ranges (e.g., restricting a fader from sending values 0–127 down to a subtle 40–80) or invert sweeps for crossfading between two different instruments using a single physical knob.
  • Sysex and Complex Data Handling: The software translates standard controller knobs into System Exclusive (SysEx) strings, enabling modern USB controllers to dictate parameters on vintage rackmount gear that does not support standard MIDI CC.

Dynamic Conditional Routing and State Management

Complex live sets often demand that a single physical controller change roles between songs or even song sections. Bome MIDI Translator uses internal global variables, timers, and conditional rules to handle these shifts dynamically:

  • Layering and Shift Modes: Performers can program "shift" buttons or toggles. Pressing a button changes a global state, instantly remapping a 16-pad controller from triggering drum samples to firing backing tracks or changing mixer parameters.
  • Song-Specific Presets: Entire routing maps can be grouped into presets that activate automatically upon receiving a specific Program Change message from a master setlist DAW.
  • Rules and Processing Logic: Performers can implement "if/then" rules—such as dropping specific velocity layers, creating split zones across a single keyboard, or delaying specific messages with built-in timers to prevent accidental double-triggers.

Multi-Destination Splitting and Merging

Hardware MIDI setups typically require daisy chains or physical patchbays to distribute signals. Bome replaces or augments physical hardware routing using comprehensive software routing matrices:

  • One-to-Many Routing: A single controller press can simultaneously send a note to a stage synth, trigger a lighting cue via an external DMX-over-MIDI app, and update a vocal effects processor.
  • Many-to-One Merging: Inputs from multiple keyboards, electronic drum kits, and foot controllers can be merged into a single clean stream, preventing message collisions and timing jitter before reaching the main performance DAW.

Hardware Port Virtualization and Redundancy

One of the greatest hazards in a live performance is an accidental USB disconnect, which can cause DAWs to lose controller recognition and freeze the audio engine. Bome MIDI Translator solves this through virtual ports:

  • Virtual MIDI Ports: The performance DAW connects exclusively to persistent, virtual MIDI ports created by Bome, rather than the physical USB devices directly.
  • Hot-Swapping Protection: If a physical USB cable is unplugged on stage, the DAW never sees the disconnection because the virtual port remains open. Once the physical cable is reconnected, Bome automatically resumes routing without requiring the performer to restart the DAW or reconfigure the session mid-show.
