How MIDI to CV Converters Map Pitch to 1V/Oct

A MIDI-to-Control-Voltage (MIDI-to-CV) converter bridges the digital protocol of MIDI with the analog world of modular synthesizers by translating discrete digital note numbers into continuous control voltages. This article explains the underlying mathematics, hardware processes, digital-to-analog conversion, and calibration techniques used to translate 7-bit MIDI Note On messages into the standard 1 Volt-per-Octave (1V/Oct) analog pitch format.

The Pitch Standards

The conversion process relies on aligning two completely different representations of musical pitch:

  • MIDI Note Numbers: MIDI represents pitch using a 7-bit integer ranging from 0 to 127. Each increment of 1 represents a semitone in standard 12-tone equal temperament. An octave spans exactly 12 semitones. For example, Note 60 is standard Middle C (C4), Note 61 is C#4, and Note 72 is C5.
  • The 1V/Oct Standard: Widely popularized by Moog and standard in Eurorack systems, this standard requires a linear increase of precisely 1.000 Volt to double the frequency of an analog oscillator (raising the pitch by one octave). Because an octave contains 12 semitones, each individual semitone corresponds to an increase of exactly 1/12th of a Volt:

\[\frac{1\text{ V}}{12\text{ semitones}} \approx 0.08333\text{ V} \text{ (or } 83.33\text{ mV per semitone)}\]

The Mathematical Mapping

When a converter receives a 3-byte MIDI Note On message (Status byte, Note Number, Velocity), the onboard microcontroller extracts the Note Number (0–127).

To map this integer to a voltage, the processor establishes a reference base note (often Note 0, Note 24, or Note 36) mapped to 0 Volts. The target output voltage (\(V_{\text{out}}\)) is calculated using the formula:

\[V_{\text{out}} = \frac{\text{MIDI Note} - \text{Base Note}}{12}\]

For example, using MIDI Note 36 (C2) as a 0V baseline:

  • Note 36 (C2): \((36 - 36) / 12 = 0.000\text{ V}\)
  • Note 48 (C3): \((48 - 36) / 12 = 1.000\text{ V}\)
  • Note 60 (C4): \((60 - 36) / 12 = 2.000\text{ V}\)
  • Note 61 (C#4): \((61 - 36) / 12 \approx 2.0833\text{ V}\)

The Conversion Pipeline

The physical transition from digital data to an analog voltage involves three primary stages:

1. Processing and Digital Representation

The microcontroller takes the target voltage and converts it into a digital binary value suitable for a Digital-to-Analog Converter (DAC). Many implementations use a lookup table (LUT) containing pre-calculated values for all 128 MIDI notes to reduce computational overhead and eliminate floating-point rounding errors during performance.

2. Digital-to-Analog Conversion (DAC)

A high-resolution DAC converts the digital representation into a raw electrical potential. DAC resolution is critical for accurate pitch tracking:

  • 8-bit DAC: Offers only 256 discrete steps. Across an 8-octave range (0–8V), this yields roughly 31.25 mV per step, which is too coarse to track an 83.33 mV semitone without severe intonation errors.
  • 12-bit DAC: Provides 4,096 discrete steps. Over a 0–10V range (10 octaves), the step size is approximately 2.44 mV, which corresponds to less than 3 cents of pitch error—the minimum acceptable resolution for musical pitch.
  • 16-bit DAC: Delivers 65,536 discrete steps, reducing voltage step size to roughly 0.15 mV (less than 0.2 cents of pitch error), effectively eliminating audible quantization error.

3. Analog Conditioning and Buffering

Most DACs output voltages between 0V and 3.3V or 5V. Because Eurorack pitch inputs typically expect a range of 0V to +10V (or -5V to +5V), the signal passes through precision operational amplifiers (op-amps).

The op-amp circuit scales the voltage to the required amplitude and buffers the output. Buffering ensures a very low output impedance so that connecting multiple oscillator inputs does not cause a voltage drop that detunes the instruments.

Calibration and Precision

Analog components have manufacturing tolerances and temperature dependencies that can distort the exact 1/12V step ratio. If the output voltage is off by merely 1 millivolt, human ears can detect the resulting pitch drift.

To maintain strict tracking across multiple octaves, converters use two tuning controls, implemented either via physical potentiometers (trimmers) or software calibration routines:

  • Offset (Zero): Adjusts the baseline voltage for the lowest note to ensure 0V is accurately anchored.
  • Scale (Gain): Adjusts the amplification factor to ensure that moving up 12 MIDI notes yields exactly an additional 1.000V across the entire playable range.
