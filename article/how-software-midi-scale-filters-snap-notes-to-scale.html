How Software MIDI Scale Filters Snap Notes to Scale

A software MIDI scale filter forces off-key notes into a designated modal scale by intercepting incoming MIDI note messages, analyzing their pitch values against an allowed set of scale degrees, and dynamically shifting non-conforming pitches to the nearest valid note in real time. This process, often referred to as pitch quantization or scale snapping, alters the raw numerical pitch data of a performance before the signal reaches a virtual instrument, ensuring every generated sound fits perfectly within a chosen harmonic framework.

The Foundation: MIDI Note Numbers and Modulo Arithmetic

MIDI represents pitch information using integer values ranging from 0 to 127, where each integer corresponds to a specific semitone (for example, Middle C is MIDI note 60). Because Western musical scales repeat every octave (12 semitones), scale filters evaluate incoming notes using modulo 12 arithmetic.

When a note is played, the software calculates:

\[\text{Pitch Class} = \text{MIDI Note Number} \pmod{12}\]

This calculation isolates the note's pitch class (a value from 0 to 11, representing C through B) independent of its octave register.

Defining the Modal Scale

A designated modal scale is stored within the filter as a binary array, a bitmask, or a lookup table containing the allowed pitch classes. For example, the C Dorian mode consists of the notes C, D, E♭, F, G, A, and B♭. In a 12-semitone pitch-class set, this corresponds to:

  • Allowed: {0, 2, 3, 5, 7, 9, 10}
  • Prohibited (Off-Key): {1, 4, 6, 8, 11} (D♭, E, F♯, A♭, B)

If the incoming pitch class matches a value in the allowed set, the note passes through the filter unaltered.

The Snapping Algorithm

When an incoming pitch class matches a prohibited value, the snapping algorithm determines the correction offset. The filter measures the absolute distance in semitones between the prohibited note and the nearest allowed notes in the scale array:

  1. Distance Calculation: The software identifies the closest valid scale degrees directly above and below the off-key note.
  2. Nearest-Neighbor Selection: The note is automatically shifted by adding or subtracting semitones to match the closest valid pitch class. For instance, playing an E natural (pitch class 4) in C Dorian puts it equidistant between E♭ (3) and F (5).
  3. Tie-Breaking Logic: When an off-key note sits directly between two valid scale degrees, the algorithm uses a predefined rule to resolve the tie. Most plugins allow the user to prioritize snapping down, snapping up, or following the direction of the previous note played.

Preserving Octaves and Performance Data

Once the corrected pitch class is determined, the filter recalculates the final MIDI note number by restoring the original octave register:

\[\text{Corrected Note} = (\text{Octave} \times 12) + \text{Snapping Offset}\]

Crucially, the scale filter only modifies the pitch byte within the three-byte MIDI "Note On" and "Note Off" messages. Velocity (dynamics), polyphonic aftertouch, note duration, and modulation data remain intact. The entire calculation occurs within microseconds, allowing live performers to play without perceptible latency while guaranteeing that every output note conforms to the specified mode.
