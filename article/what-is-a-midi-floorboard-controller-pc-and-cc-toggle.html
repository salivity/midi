What Is a MIDI Floorboard Controller: PC and CC Toggle

A MIDI floorboard controller is a foot-operated hardware device that allows musicians to control digital audio gear, amplifiers, multi-effects processors, and DAWs without using their hands. This guide covers what these controllers do, the technical differences between Program Change (PC) and Control Change (CC) messages, and the specific switching methods devices use to toggle between loading complete presets and manipulating individual real-time parameters.

Understanding the MIDI Floorboard Controller

A MIDI floorboard controller consists of heavy-duty footswitches and optional expression pedals housed in a rugged chassis. Rather than processing audio directly, the unit generates and transmits standard digital MIDI commands via traditional 5-pin DIN cables, TRS jacks, or USB. When connected to compatible equipment—such as digital amp modelers, rackmount processors, or software plugins—it gives the performer hands-free command over preset selection, parameter adjustments, and tempo synchronization.

Program Change vs. Control Change Messages

To understand how a floorboard operates, you must distinguish between the two primary message types it transmits:

  • Program Change (PC): PC messages tell a receiving device to switch from one patch, preset, or channel to another. Values range from 0 to 127. For instance, sending PC #1 might load a clean acoustic simulator, while sending PC #2 recalls a high-gain solo sound with entirely different routing, amps, and effects chains.
  • Control Change (CC): CC messages alter specific variables within an already active preset. A CC message includes both a controller number (0–127) to identify the target parameter and a value (0–127) to specify the setting. Guitarists frequently use CC messages to toggle individual effects on and off (like a virtual stompbox) or to control variable functions like volume, wah, and delay feedback via continuous expression pedals.

How Floorboards Toggle Between PC and CC Messages

Floorboard controllers use several firmware-level methods to switch between sending PC and CC data on demand:

1. Bank and Mode Switching

Most modern controllers feature distinct operational modes. In Preset Mode, every footswitch sends a fixed PC message to recall patches across multiple banks. Pressing a designated "Mode" switch transitions the unit into Stompbox (or CC) Mode, where the exact same switches re-map to send CC commands that bypass or activate individual overdrive, modulation, or delay blocks within the current patch.

2. Hybrid Layouts

Many professional boards allow simultaneous access to both message types without changing modes. For example, a 10-button controller can be programmed so the bottom row of switches transmits PC messages (1 through 5) for instant patch changes, while the top row exclusively sends CC messages to engage lead boosts, tap tempo, or tuner mutes.

3. Press-and-Hold (Multi-Action Switching)

Advanced controllers utilize secondary switch behaviors based on how long a foot pedal is depressed:

  • Short Tap: Sends a PC message to change the patch immediately.
  • Long Hold: Sends a CC message, such as engaging a solo boost or activating a continuous tuner.
  • Double Tap: Can be assigned to toggle secondary CC values or jump to an alternate bank.

4. Latching vs. Momentary CC Toggles

When a switch is configured for CC operation, the controller must toggle between two operational states:

  • Latching (Toggle): Pressing the switch once sends a CC value of 127 (Effect ON). Pressing it again sends a CC value of 0 (Effect OFF). LED indicators on the floorboard illuminate or change color to show the active state.
  • Momentary (Unlatched): The switch sends a value of 127 only while held down and drops back to 0 immediately upon release, which is ideal for momentary freeze effects or manual pitch dives.
