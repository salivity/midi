Web MIDI API: Iterating Connected Input Ports

The Web MIDI API enables web applications to interact directly with hardware musical instruments and controllers. Once a session is established using navigator.requestMIDIAccess(), the resulting MIDIAccess object exposes the inputs property, which represents all currently connected MIDI input devices. This article outlines the built-in methods provided by the API to iterate through these hardware input ports, detailing how to access and manage the underlying MIDIInputMap.

Accessing the Input Map

Requesting access via navigator.requestMIDIAccess() resolves a promise with a MIDIAccess object. The midiAccess.inputs property returns a MIDIInputMap instance. The MIDIInputMap interface is modeled after the standard ECMAScript Map structure, functioning as a read-only collection of MIDIInput ports keyed by their unique device identifiers.

const midiAccess = await navigator.requestMIDIAccess();
const inputs = midiAccess.inputs;

1. Using the forEach() Method

The MIDIInputMap implements a forEach() method identical to that of the standard JavaScript Map. It executes a provided callback function once per connected input port.

midiAccess.inputs.forEach((input, key) => {
  console.log(`Port ID: ${key}`);
  console.log(`Device Name: ${input.name}`);
  console.log(`Manufacturer: ${input.manufacturer}`);
  console.log(`State: ${input.state}`);
});

The callback accepts three arguments: the MIDIInput object, the port's unique string ID, and the MIDIInputMap itself.

2. Using the values() Iterator

When you only need the device instances and not their map keys, the values() method returns a new iterable iterator containing the MIDIInput objects for each port.

for (const input of midiAccess.inputs.values()) {
  console.log(`Connected Input: ${input.name} (${input.id})`);
}

This is typically the cleanest approach for attaching incoming message listeners (onmidimessage) to every available hardware input.

3. Using Direct Iteration or entries()

Because MIDIInputMap implements the iterable protocol, it can be passed directly to a for...of loop. The default iterator returns key-value pairs identical to calling the entries() method, where each item is a [portId, inputPort] array.

// Direct iteration using the default iterator
for (const [id, input] of midiAccess.inputs) {
  console.log(`Device ID: ${id}, Name: ${input.name}`);
}

// Explicit iteration via entries()
for (const [id, input] of midiAccess.inputs.entries()) {
  console.log(`Device ID: ${id}, Name: ${input.name}`);
}

4. Using the keys() Iterator

If you only need to inspect or record the identifiers of the connected hardware ports, the keys() method provides an iterator containing the unique string ID for each connected device.

for (const portId of midiAccess.inputs.keys()) {
  console.log(`Available Port ID: ${portId}`);
}

5. Converting to a Standard Array

For scenarios requiring standard array manipulation methods (such as filter, map, or reduce), the iterators provided by MIDIInputMap can be converted into standard JavaScript arrays using Array.from() or the spread operator (...).

// Convert input values into an array
const inputList = Array.from(midiAccess.inputs.values());

// Filter connected ports by manufacturer
const specificDevices = inputList.filter(input => input.manufacturer === "TargetManufacturer");
