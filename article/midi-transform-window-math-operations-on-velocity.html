MIDI Transform Window: Math Operations on Velocity

A MIDI transform window is an advanced digital audio workstation (DAW) utility designed to process, filter, and modify MIDI performance data using rule-based algorithmic instructions. While standard editing requires manual adjustments or basic quantization, a transform window allows producers to target specific MIDI events—such as note pitches, lengths, or velocities—and alter them systematically. When applied to velocity, the transform window executes mathematical functions across selected notes to alter dynamic range, correct human performance inconsistencies, or automate expressive variation without requiring manual redrawing.

Understanding the MIDI Transform Window

Found in DAWs such as Apple Logic Pro (Transform Window), Steinberg Cubase (Logical Editor), and Presonus Studio One, this tool operates on an "If/Then" conditional logic system. The user defines two primary parameter blocks:

  1. Conditions (Input/Filter): Determines which events are affected. Criteria can include event type (Notes, Control Change, Pitch Bend), specific pitch ranges, position within a bar, or existing velocity values.
  2. Operations (Output/Action): Dictates how the parameters of those filtered events will be modified.

Velocity represents the speed and force with which a MIDI note is struck, expressed as an integer between 1 and 127 (with 0 functioning as a note-off event). In a MIDI transform window, this integer serves as a numerical variable that can be manipulated using basic to complex arithmetic.

Mathematical Operations Applied to Velocity

By targeting the "Velocity" parameter column within the action block, the transform window can apply several distinct mathematical operators:

1. Addition and Subtraction (Offset)

  • Operation: \(V_{new} = V_{current} \pm n\)
  • Function: Adds or subtracts a fixed integer from the existing velocity of every targeted note.
  • Use Case: Increasing or decreasing the overall loudness of a performance while preserving the relative volume differences between individual notes. Built-in boundary limits ensure the value does not drop below 1 or exceed 127.

2. Multiplication and Division (Scaling and Compressing)

  • Operation: \(V_{new} = V_{current} \times n\) or \(V_{new} = V_{current} \div n\) (often represented as a factor, such as \(0.8\) or \(1.25\))
  • Function: Multiplies the velocity value by a designated ratio.
  • Use Case: Acting as a MIDI-level dynamic expander or compressor. Multiplying by a decimal less than 1.0 narrows the dynamic range by pulling louder notes closer to softer ones. Multiplying by a factor greater than 1.0 increases the dynamic spread between soft and hard hits.

3. Scaling to a Range (Remapping)

  • Operation: Linear interpolation mapping an input range \([A, B]\) to an output range \([C, D]\).
  • Function: Compresses or expands existing velocity dynamics to fit strictly within newly defined minimum and maximum boundaries.
  • Use Case: Ensuring a drum track remains within an expressive sweet spot (e.g., remapping a performance that ranges from 30–120 into a controlled range of 75–105) without clipping or flattening the performance.

4. Randomization (Stochastic Variation)

  • Operation: \(V_{new} = V_{current} \pm \text{Random}(0, n)\)
  • Function: Introduces a controlled pseudo-random integer within a specified deviation limit (\(n\)) to the existing velocity value.
  • Use Case: "Humanizing" programmed or quantized MIDI tracks where uniform velocities sound robotic. Adding a random range of \(\pm 5\) produces natural, subtle dynamic variance across hi-hats, piano chords, or rhythm sections.

5. Fixed Assignment (Constant Replacement)

  • Operation: \(V_{new} = n\)
  • Function: Completely overrides the current velocity and assigns a static numerical value across all filtered notes.
  • Use Case: Creating hard-hitting, consistent electronic patterns, such as setting all kick drum hits to an absolute value of 127.

6. Inversion

  • Operation: \(V_{new} = 127 - V_{current}\) (or based around a user-defined median)
  • Function: Reverses the dynamic values, turning the softest notes into the loudest and vice versa.
  • Use Case: Creative sound design, ghost-note accentuation, or producing reversed dynamic envelopes across looped patterns.
