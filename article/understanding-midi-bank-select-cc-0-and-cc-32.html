Understanding MIDI Bank Select CC 0 and CC 32

Standard MIDI Program Change messages are inherently limited to selecting only 128 individual sounds due to MIDI's 7-bit data architecture. To overcome this limitation and navigate modern sound libraries containing thousands of presets, the MIDI specification pairs Control Change 0 (CC 0) and Control Change 32 (CC 32) as a Bank Select mechanism. This guide explains how these two control messages combine to address 128 banks of 128 patches each, detailing the underlying data structure and transmission sequence.

The 7-Bit Limitation and the Role of Bank Select

A standard MIDI Program Change (PC) message uses a single 7-bit data byte, allowing values from 0 to 127. This means a single PC command can address a maximum of 128 patches.

To expand this capacity, the MIDI specification designates two Continuous Controllers to act as bank selectors:

  • CC 0 (Bank Select MSB): Most Significant Byte (coarse adjustment).
  • CC 32 (Bank Select LSB): Least Significant Byte (fine adjustment).

Each of these controllers also carries a 7-bit value (0–127). When combined, CC 0 and CC 32 form a 14-bit number capable of addressing up to 16,384 distinct banks (\(128 \times 128\)). When followed by a standard Program Change message, a MIDI device could theoretically access up to 2,097,152 unique patches (\(16,384 \times 128\)).

Configuring 128 Banks of 128 Patches

When a hardware synthesizer or virtual instrument requires access to exactly 128 banks—with each bank containing 128 patches—it only needs 7 bits of bank addressing space (\(2^7 = 128\)). Manufacturers typically implement this structure using one of two methods:

  1. MSB Only (CC 0 Active, CC 32 Fixed):
    The bank number (0 to 127) is transmitted via CC 0 (MSB). Because the fine-tuning byte is not needed for only 128 banks, CC 32 (LSB) is transmitted with a constant value of 0 (or ignored by the receiving device).

  2. LSB Only (CC 0 Fixed, CC 32 Active):
    Some manufacturers assign CC 0 to 0 and use CC 32 to cycle through the 128 banks (values 0 to 127).

In both configurations, the active controller provides the 128 unique bank addresses, while the secondary controller remains static to fulfill the standard two-byte MIDI Bank Select protocol.

The Transmission Sequence

Bank Select messages do not change a sound on their own. They simply update the internal pointer of the receiving device. The actual sound change occurs only when a subsequent Program Change message is received.

To select a specific patch from this matrix, the transmitting controller sends a precise three-message sequence:

  1. Send CC 0 (Bank Select MSB): Transmits Controller 0 with a value representing the target bank (e.g., Value = 2 for Bank 2).
  2. Send CC 32 (Bank Select LSB): Transmits Controller 32 with a value (typically Value = 0 to complete the 14-bit bank address).
  3. Send Program Change: Transmits the Program Change command with a value from 0 to 127 to select the specific patch within the bank defined by steps 1 and 2.

Practical Example

To load Patch 45 located inside Bank 12:

  • Message 1: CC 0, Value 12 (Sets the MSB bank address to 12)
  • Message 2: CC 32, Value 0 (Sets the LSB bank address to 0)
  • Message 3: Program Change, Value 45 (Loads Patch 45 from the armed Bank 12)

By maintaining CC 32 at zero and varying CC 0 between 0 and 127, the system seamlessly navigates 128 dedicated banks, each housing 128 individual patches selected by the final Program Change command.
