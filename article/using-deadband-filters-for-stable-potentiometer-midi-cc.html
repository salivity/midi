Using Deadband Filters for Stable Potentiometer MIDI CC

Converting continuous analog potentiometer signals into digital MIDI Control Change (CC) messages often introduces electrical noise and unintended value fluctuations. An analog deadband filter is an algorithmic thresholding technique that suppresses this noise by ignoring minor voltage micro-variations. Implementing a deadband filter is essential for creating stable, jitter-free MIDI controllers, as it prevents phantom MIDI messages, reduces bandwidth saturation, and ensures parameters remain steady until the user deliberately turns a knob.

The Problem: ADC Noise and Boundary Oscillation

Analog-to-digital converters (ADCs) in microcontrollers typically sample potentiometer voltage at 10-bit (0–1023) or 12-bit (0–4095) resolution. In real-world circuits, analog voltages are subject to thermal noise, power supply ripple, and mechanical imperfections. Consequently, an untouched potentiometer rarely outputs a completely static ADC value; it naturally fluctuates up and down by a few units.

Standard MIDI CC values operate on a 7-bit scale, ranging from 0 to 127. To convert a 10-bit ADC reading into MIDI, the system divides the reading by 8. If the potentiometer sits on a numerical boundary—such as an ADC value oscillating between 511 and 512—this downscaled value repeatedly flips between MIDI values 63 and 64.

Without filtering, this boundary oscillation causes three major problems:

  • MIDI Flooding: The microcontroller sends a continuous stream of redundant MIDI messages, consuming serial bandwidth and introducing latency into the system.
  • Audible Artifacts: Connected software synths or digital audio workstations (DAWs) constantly modulate the assigned parameter, causing audible clicks, zipper noise, or unintended automation writes.
  • CPU Overhead: Receiving hardware or software must process thousands of unnecessary messages per second.

What Is a Deadband Filter?

A deadband filter—closely related to hysteresis—is a software logic mechanism that creates an inactive zone (the "deadband") around the current measurement. Under this rule, a change in the input signal is discarded unless the magnitude of that change exceeds a predefined threshold.

Instead of sending every minor change detected by the ADC, the algorithm compares the current sensor reading to the last registered value. If the difference is smaller than the deadband threshold, the system treats the input as noise and takes no action. Only when the user intentionally turns the potentiometer past this threshold does the filter accept the new value, transmit the updated MIDI CC, and reset the reference point.

How the Filter Operates

In a typical potentiometer-to-MIDI pipeline, the deadband filter works as follows:

  1. Read Analog Input: The ADC reads the instantaneous potentiometer voltage.
  2. Calculate Delta: The algorithm computes the absolute difference between the new ADC reading and the last accepted reading (abs(current_reading - last_reading)).
  3. Threshold Check:
    • If the delta is less than the deadband size (typically 2 to 4 steps for a 10-bit ADC), the reading is ignored.
    • If the delta meets or exceeds the deadband, the change is recognized as intentional user input.
  4. Update and Map: The algorithm updates the stored reference value and maps the new value to the 0–127 MIDI CC range.
  5. Transmit: The microcontroller sends the MIDI CC message out over USB or standard 5-pin DIN.

Why Deadband Filtering Is Essential for MIDI

Standard smoothing filters, such as moving averages or low-pass exponential filters, reduce high-frequency noise but introduce latency and do not completely resolve boundary jitter. An averaged value can still drift slowly across a MIDI boundary, causing delayed, ghost messages to transmit long after the user has released the knob.

A deadband filter provides definitive stability. Once a user stops moving a control, the output locks instantly. It achieves absolute stillness without introducing sluggish control lag, making the physical hardware feel responsive, accurate, and professional.
