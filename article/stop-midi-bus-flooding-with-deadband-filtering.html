Stop MIDI Bus Flooding with Deadband Filtering

Analog potentiometers read by microcontrollers are prone to electrical noise and analog-to-digital converter (ADC) quantization jitter, which can cause micro-fluctuations that flood a MIDI bus with continuous, redundant Control Change (CC) messages. Implementing deadband filtering creates a noise-rejection threshold that ignores fluctuations below a specified amplitude. This article explains how firmware developers can implement deadband algorithms at the firmware level, ensuring stable parameter tracking, responsive control, and an unburdened MIDI stream.

The Root Cause of MIDI Flooding

Standard 5-pin DIN MIDI operates at a modest 31.25 kbaud, meaning each 3-byte Control Change message takes roughly 1 millisecond to transmit. While USB-MIDI provides significantly higher bandwidth, excessive transmission still wastes CPU cycles, overflows buffers, and can introduce jitter into time-critical MIDI clock or note events.

Microcontrollers typically read potentiometer values using 10-bit or 12-bit ADCs (0–1023 or 0–4095) before scaling the result down to the standard 7-bit MIDI range (0–127). If a knob sits on the boundary between two values, high-frequency circuit noise causes the ADC reading to rapidly alternate between states. Without filtering, the firmware repeatedly fires MIDI messages even when the physical knob is completely stationary.

How Deadband Filtering Works

Deadband filtering establishes a dynamic threshold around the last transmitted value. A new value is accepted and transmitted only if the change in the raw ADC signal exceeds a predefined deadband window (\(\pm \Delta\)). Once the change exceeds this threshold, the internal reference shifts to the new position.

To prevent erratic stepping, developers should apply the deadband to the high-resolution raw ADC data before scaling to the 7-bit MIDI range, rather than applying it directly to the 0–127 output.

Basic C Implementation

Below is a robust implementation demonstrating deadband filtering alongside scaling to 7-bit MIDI:

#include <stdint.h>
#include <stdlib.h>
#include <stdbool.h>

#define ADC_MAX_VAL 4095        // 12-bit ADC
#define DEADBAND_THRESHOLD 16    // Noise threshold (tuning parameter)

typedef struct {
    uint16_t last_stable_adc;
    uint8_t last_midi_val;
} Potentiometer;

bool process_potentiometer(Potentiometer *pot, uint16_t current_adc, uint8_t *midi_out) {
    int32_t diff = (int32_t)current_adc - (int32_t)pot->last_stable_adc;

    // Check if the change exceeds the deadband threshold
    if (abs(diff) >= DEADBAND_THRESHOLD) {
        pot->last_stable_adc = current_adc;

        // Scale to 7-bit MIDI (0 - 127)
        uint8_t new_midi_val = (uint8_t)((current_adc * 127) / ADC_MAX_VAL);

        // Only send if the final scaled MIDI value has changed
        if (new_midi_val != pot->last_midi_val) {
            pot->last_midi_val = new_midi_val;
            *midi_out = new_midi_val;
            return true; // Send MIDI message
        }
    }

    return false; // Suppress message
}

Handling Boundary Edge Cases

A naive deadband implementation can prevent knobs from reliably reaching absolute minimum (0) or maximum (127) values if the remaining travel is smaller than the deadband threshold. To resolve this, clamp boundaries unconditionally:

if (current_adc <= DEADBAND_THRESHOLD) {
    current_adc = 0;
} else if (current_adc >= (ADC_MAX_VAL - DEADBAND_THRESHOLD)) {
    current_adc = ADC_MAX_VAL;
}

This ensures that turning the knob to physical lockouts always yields clean, definitive 0 or 127 transmissions.

Combining Deadband with Exponential Moving Averages

For optimal performance, combine deadband filtering with a lightweight low-pass filter, such as an Exponential Moving Average (EMA). The EMA smooths out high-frequency noise spikes, while the deadband eliminates the persistent low-amplitude baseline jitter:

  1. Read ADC: Sample the analog channel.
  2. Apply EMA: filtered_adc = (alpha * current_adc) + ((1 - alpha) * filtered_adc)
  3. Apply Deadband: Evaluate filtered_adc against the stored reference.
  4. Emit Message: Transmit only when the filtered value crosses the deadband and maps to a distinct 7-bit MIDI integer.

This hybrid approach allows developers to maintain low latency during deliberate turns while completely silencing the MIDI bus when controllers are untouched.
