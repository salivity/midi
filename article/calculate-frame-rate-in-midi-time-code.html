Calculate Frame Rate in MIDI Time Code

This article explains how to determine the exact frame rate from a MIDI Time Code (MTC) full frame payload. By examining the structure of the Universal System Exclusive message and applying a specific bitwise calculation to the hours byte, software and hardware decoders identify whether a stream is operating at 24, 25, 29.97 drop-frame, or 30 frames per second.

The Full Frame Payload Structure

An MTC Full Frame message is transmitted as a Universal Real-Time System Exclusive (SysEx) message formatted as follows:

F0 7F [deviceID] 01 01 [hr] [mn] [sc] [fr] F7

  • F0 7F: Universal Real-Time SysEx header
  • [deviceID]: Target device ID (often 7F for all call)
  • 01 01: Sub-IDs indicating an MTC Full Frame message
  • [hr]: Encoded Hours and Time Code Type byte
  • [mn]: Minutes (00–59)
  • [sc]: Seconds (00–59)
  • [fr]: Frames (00–29)
  • F7: End of Exclusive (EOX)

The Bitwise Calculation

MTC does not transmit the frame rate as an arbitrary numerical value or directly inside the frames ([fr]) byte. Instead, the frame rate is encoded directly within the two most significant data bits of the hours byte ([hr]).

To calculate the 2-bit frame rate identifier from the hours byte, apply the following bitwise operation:

\[\text{Rate Code} = (\text{hr} \ \& \ \text{0x60}) \gg 5\]

Alternatively:

\[\text{Rate Code} = \lfloor \text{hr} / 32 \rfloor \pmod 4\]

This isolates bits 5 and 6 of the 7-bit MIDI data byte:

  • Bit 7: Always 0 (standard MIDI data byte requirement)
  • Bits 6–5: Encoded Frame Rate Type (00, 01, 10, or 11)
  • Bits 4–0: Actual Hours value (\(0\)–\(23\))

Frame Rate Mapping

Once the 2-bit integer value (ranging from 0 to 3) is extracted, it maps to the exact SMPTE frame rate:

Rate Code (Binary) Rate Code (Decimal) Standard Frame Rate Exact Mathematical Value
00 0 24 fps \(24.0\) fps
01 1 25 fps \(25.0\) fps
10 2 29.97 fps (Drop Frame) \(\frac{30000}{1001} \approx 29.97002997\) fps
11 3 30 fps (Non-Drop) \(30.0\) fps

Example

If the received hours byte is 0x65 (binary 01100101):

  1. Mask with 0x60 (01100000): 0x65 & 0x60 = 0x60
  2. Shift right by 5 bits: 0x60 >> 5 = 3 (binary 11)
  3. Look up rate code 3: The exact frame rate is 30 fps Non-Drop Frame.
  4. Mask with 0x1F (00011111) to read the hours: 0x65 & 0x1F = 5 hours.
