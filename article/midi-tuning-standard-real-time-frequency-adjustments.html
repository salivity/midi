MIDI Tuning Standard Real-Time Frequency Adjustments

This article provides an overview of the MIDI Tuning Standard (MTS) real-time frequency messages, focusing on how single-byte microtonal adjustments alter sounding notes. It explains the exact numerical resolution of these adjustments, the message structure used to transmit them, and how synthesizers interpret microtonal offsets on the fly without retriggering active voices.

The Single-Byte Microtonal Value in MTS

In the MIDI Tuning Standard, single-byte microtonal adjustments depend on the specific real-time message type being transmitted:

  1. Scale/Octave Real-Time Tuning (1-Byte Format): When using the MTS 1-byte Scale/Octave tuning format, each note is modified by a single 7-bit byte representing a deviation in 1-cent increments. The single byte ranges from 0x00 to 0x7F (0 to 127 in decimal), centered around 0x40 (64 decimal):
    • 0x00 (0) corresponds to a -64 cent shift.
    • 0x40 (64) corresponds to 0 cents (no microtonal change).
    • 0x7F (127) corresponds to a +63 cent shift.
  2. Standard Frequency Representation (Coarse Fraction): In the primary 3-byte MTS frequency specification (which transmits a semitone byte followed by two fractional bytes), the first fractional byte provides a single-byte coarse microtonal adjustment of 1/128 of a semitone, which equates to approximately 0.78125 cents per step.

How Real-Time MTS Frequency Messages Work

The real-time MIDI Tuning Standard message is a System Exclusive (SysEx) command designed to retune active notes instantly without requiring the note to be re-struck (Note-Off followed by Note-On).

Single-Note Real-Time Retuning

The standard single-note real-time retuning command uses the following SysEx structure:

F0 7F <device ID> 08 02 <tuning program> <tuning bank> <number of changes> [<note number> <freq byte 1> <freq byte 2> <freq byte 3>] F7
  • Note Number: The target MIDI key (0–127).
  • Frequency Byte 1: The base semitone value (0–127), referencing standard equal temperament pitch.
  • Frequency Byte 2: The coarse microtonal fraction (1/128th semitone resolution).
  • Frequency Byte 3: The fine microtonal fraction (1/16,384th semitone resolution, or ~0.0061 cents).

When only a coarse microtonal modification is evaluated at the single-byte level, Frequency Byte 2 governs the primary microtonal offset at the 0.78125-cent scale.

Octave and Scale Real-Time Retuning

For broader retuning across the keyboard, the 1-byte Scale/Octave real-time message updates 12 notes simultaneously across all octaves using 12 individual single-byte values:

F0 7F <device ID> 08 08 <bank> <preset> <byte 0> ... <byte 11> F7

Each byte (byte 0 to byte 11) corresponds to a pitch class (C through B) and dictates the microtonal offset for that note using the signed 1-cent resolution spanning from -64 cents to +63 cents.

Implementation and Sounding Note Response

When a compatible synthesizer receives a real-time MTS command containing single-byte microtonal adjustments:

  • Instant Phase Continuity: The oscillator's playback frequency shifts immediately to the target pitch calculation without phase resetting or envelope restarting.
  • Polyphonic Freedom: Unlike standard MIDI Pitch Bend messages, which affect an entire MIDI channel, MTS single-note frequency adjustments allow individual notes within a polyphonic chord to be retuned independently.
