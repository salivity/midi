MIDI Note-Off Velocity and Release Samples Explained

MIDI Note-Off velocity, commonly referred to as release velocity, measures the speed at which a key is released on a MIDI controller. While standard velocity dictates the attack volume and timbre when a note is pressed, Note-Off velocity captures the physical departure of the player's finger from the key. Modern high-end sample libraries harness this data to trigger specialized release samples, capturing authentic mechanical noises—such as piano dampers dropping and key beds resetting—to bridge the gap between static digital playback and dynamic acoustic performance.

Understanding Note-Off Velocity

Every time a key is pressed on a standard MIDI keyboard, a Note-On message is generated alongside a velocity value between 0 and 127. When the key is released, a corresponding Note-Off message is transmitted. While basic MIDI hardware transmits a fixed Note-Off value (often hardcoded to 64 or 0), expressive, weighted controllers feature sensors capable of measuring the upward travel speed of the key.

A slow, deliberate release produces a low Note-Off value (e.g., 10 to 30), whereas an abrupt, staccato release generates a high value (e.g., 90 to 127). This simple measurement gives virtual instruments crucial performance data regarding how an acoustic instrument would physically react at the end of a note.

The Physics of Key and Mechanical Noise

In acoustic instruments like the grand piano, harpsichord, or electric piano (such as a Fender Rhodes), releasing a key is an active acoustic event:

  • Damper Impact: Felt dampers drop back down onto vibrating strings. A fast release slaps the felt against the string quickly, creating an audible thud and abrupt sound termination. A slow release lets the felt gradually settle, muting high harmonics first with little to no physical impact noise.
  • Key Mechanism Clatter: The wooden key, balance rail, jack, and hammer assembly return to their resting positions. The rapid upward movement causes physical components to collide with felt bushings and resting rails, producing a sharp mechanical click or clatter.
  • Resonance Interaction: As the dampers mute the strings, the internal soundboard cavity and open strings exhibit brief acoustic decay and sympathetic resonance shifts.

How Sample Libraries Use Release Velocity

High-end sample libraries (such as high-tier virtual pianos, organs, and vintage keyboards) record mechanical release sounds as isolated, dedicated sample sets across multiple dynamic layers. When playing the instrument, the engine uses Note-Off velocity in several specific ways:

  1. Layered Sample Selection: The sampler maps Note-Off velocity values directly to specific recordings of mechanical releases. A gentle key release triggers a subtle, quiet sample of the key mechanism resetting, while a sharp staccato release triggers a loud, percussive release sample containing the full clatter of the mechanical assembly and a hard damper impact.
  2. Dynamic Crossfading and Volume Scaling: Advanced scripting engines dynamically adjust the volume, pitch, and filtering of release samples in real time. If a user releases a key with high velocity, the engine raises the high-frequency cutoff and output level of the key-up noise to simulate an energetic release.
  3. Decay-Time Modulations: The Note-Off velocity interacts with the duration the note was initially held. High-end engines calculate both the hold time and release speed: if a note is held until its sound dies naturally, the damper sound will reflect hitting a motionless string. If released while the string is vibrating vigorously at high velocity, the engine plays an aggressive muting sound.

By using real-time Note-Off velocity to trigger and shape mechanical key noises, virtual instruments eliminate the sterile, abrupt cutoffs typical of legacy synthesis. The result is an expressive, physically convincing acoustic simulation that responds naturally to every nuance of a performer's touch.
