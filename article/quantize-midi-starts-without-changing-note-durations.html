Quantize MIDI Starts Without Changing Note Durations

Quantizing MIDI typically snaps both note-on and note-off events to the musical grid, which can strip away the natural phrasing and articulation of a human performance. This guide explains how to correct timing by locking only the start of MIDI notes to the grid while strictly preserving their original durations, covering the universal mechanics of the process and specific settings across major Digital Audio Workstations (DAWs).

The Core Principle

Standard or "quick" quantization in many DAWs defaults to snapping both the note start (Note-On) and note end (Note-Off) to the selected grid division. To preserve original durations, you must configure your quantization engine to calculate the start-time offset and apply that identical time delta to the note-off event, rather than calculating the end position against the grid.

Step-by-Step Instructions by DAW

Ableton Live

  1. Select the MIDI clip to reveal the Piano Roll.
  2. Select the notes you want to quantize.
  3. Press Ctrl + Shift + U (Windows) or Cmd + Shift + U (macOS) to open the Quantize Settings dialogue instead of using the instant shortcut.
  4. Under the Quantize section, check Start.
  5. Ensure the End box is unchecked.
  6. Set the grid division and the Amount percentage to your preference, then click OK. Ableton will shift the note starts to the grid while leaving the exact lengths intact.

Logic Pro

  1. Select the MIDI region or open it in the Piano Roll.
  2. Open the Region Inspector on the left panel (or press Q for Piano Roll Quantize).
  3. In the Piano Roll, click the Quantize drop-down menu and choose your target grid resolution. By default, standard quantization in the Piano Roll only affects Note-On positions.
  4. To ensure lengths are not altered, verify that Q-Length is set to Off in the Region Inspector under the extended parameters.
  5. If note ends are being truncated by adjacent notes, ensure Overlap Correction is disabled.

REAPER

  1. Double-click the MIDI item to open the MIDI Editor.
  2. Select the notes you want to adjust and press Q to open the Quantize Events window.
  3. In the top drop-down menu, change the target setting from "Position and note end" to Position only.
  4. Check the box labeled Preserve note lengths.
  5. Adjust your grid resolution and Strength slider, then click OK.

Cubase

  1. Open the Key Editor for the target MIDI track.
  2. Go to the top toolbar and open the Quantize Panel (or navigate to MIDI > Quantize Setup).
  3. Set your desired grid value under the Grid preset.
  4. Uncheck the Auto or Length options to ensure Note-Off events are not quantized.
  5. Under the quantize rules, ensure the target is set only to Start.
  6. Click Quantize to move the note beginnings while keeping note lengths identical.

FL Studio

  1. Open the Piano Roll containing your MIDI data.
  2. Select the desired notes, or leave all unselected to quantize everything.
  3. Press Alt + Q to open the Quantizer tool.
  4. Select a basic timing template (e.g., standard sixteenth or eighth notes).
  5. Ensure the Leave durations setting is toggled on, or adjust the Duration knob so that FL Studio does not force the tail of the notes to match the grid slice.
  6. Accept the changes.

Practical Best Practices

  • Avoid Automatic Quick-Quantize: Fast-key shortcuts (such as Ctrl+U or Cmd+U in some DAWs) often apply global preferences that snap lengths. Always use the advanced quantize dialogue if you are unsure of your software's default behavior.
  • Watch for Voice Overlaps: Preserving the duration of early notes can sometimes push their ends into subsequent notes, causing unwanted overlaps in monophonic plugins. Run a quick "Legato" or "Remove Overlaps" command if playing a mono synthesizer or bass.
  • Use Iterative Quantization: If total grid alignment sounds unnatural, set the quantize strength to 50%–75%. Shifting note starts partially toward the grid while retaining durations tightens the groove while keeping the original human feel.
