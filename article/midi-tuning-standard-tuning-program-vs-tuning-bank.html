MIDI Tuning Standard: Tuning Program vs Tuning Bank

The MIDI Tuning Standard (MTS) provides a standardized protocol for transmitting microtonal tuning data between synthesizers and software. Within this standard, pitch configurations are organized hierarchically: an individual musical tuning program contains the precise frequency definitions for individual notes, while a tuning bank acts as a container that groups up to 128 individual tuning programs together. Understanding this distinction is essential for implementing microtonality, alternate temperaments, and dynamic scale changes in MIDI-compatible instruments.

What Is a Tuning Program?

A tuning program in the MIDI Tuning Standard represents a single, complete tuning map or scale. It defines the exact pitch assignments for MIDI note numbers 0 through 127.

Key attributes of an individual tuning program include:

  • Pitch Precision: Each note in the program is defined using a three-byte frequency format (semitone, fractional semitone MSB, and fractional semitone LSB), allowing for sub-cent microtonal accuracy (approximately 0.0061 cents).
  • Scope: A single tuning program maps all 128 playable MIDI notes to specific frequencies. It can represent standard 12-tone equal temperament, historical temperaments (such as Meantone or Just Intonation), non-octave scales, or custom microtonal scales.
  • Addressing: Tuning programs are indexed from 0 to 127 within a given bank.

What Is a Tuning Bank?

A tuning bank is a higher-level organizational structure designed to store and manage multiple tuning programs. The original MTS specification supported only 128 individual tuning programs. To expand storage capacity without exhausting available address space, the standard was updated to incorporate tuning banks.

Key attributes of an individual tuning bank include:

  • Capacity: Each tuning bank holds exactly 128 individual tuning programs (numbered 0–127).
  • Addressing Range: The standard supports up to 128 tuning banks (numbered 0–127).
  • Total Capacity: Combined, the 128 banks and 128 programs yield a total capacity of 16,384 unique tuning programs accessible across a MIDI system.

How MTS Distinguishes Between the Two in Practice

The MIDI Tuning Standard differentiates programs and banks through specific System Exclusive (SysEx) and controller messages:

  • Tuning Dump Messages: MTS uses bulk dump messages to transfer complete scale data. When dumping an entire tuning map, the message includes bytes specifying both the target bank number and the target program number, ensuring the frequency data is written to the correct location in memory.
  • Real-Time Switching: Musicians can switch tunings during a performance using MIDI messages. A standard MTS Bank Change message instructs the receiving instrument which of the 128 banks to reference, while an MTS Program Change message selects the active scale within that bank. Instruments can also assign distinct tuning bank and program combinations to specific MIDI channels, allowing multi-timbral setups with multiple simultaneous tunings.
