How Hexaphonic Pickups Map MIDI for String Bends

Hexaphonic pickups bridge the gap between traditional guitars and digital synthesizers by isolating each string's audio signal at the physical level. This article explains how divided pickups isolate individual string vibrations, route them through dedicated polyphonic MIDI channels using MIDI Mono Mode, and generate independent Pitch Bend messages to accurately track techniques like single-string bends without altering neighboring sustained notes.

Physical Isolation of the Strings

Standard guitar pickups sum the vibrations of all six strings into a single monophonic output. A hexaphonic (or divided) pickup contains six individual, magnetically isolated coils—one dedicated to each string. When a string vibrates, only its corresponding pole piece captures the signal. This design virtually eliminates crosstalk, outputting six discrete analog audio signals via a multi-pin cable (such as a 13-pin DIN cable) directly to a guitar-to-MIDI converter.

Pitch and Frequency Detection

Once the six independent audio streams enter the converter, digital signal processors (DSPs) analyze each string concurrently. The processor tracks:

  • Frequency: Measuring the fundamental frequency to determine the exact note played.
  • Amplitude: Measuring the strength of the attack to generate MIDI Note Velocity.
  • Continuous Pitch Shifts: Tracking real-time microtonal fluctuations caused by vibrato, slides, or bends.

Because each string is processed on an isolated digital track, the converter can detect the frequency rise of a bent string in real time without conflicting harmonics from other ringing strings.

MIDI Mode 4 (MIDI Mono Mode)

The primary limitation of traditional MIDI 1.0 is that Pitch Bend is a channel-wide message. If multiple notes exist on a single MIDI channel, applying a pitch bend shifts every active note simultaneously. To resolve this, hexaphonic systems utilize MIDI Mode 4, commonly known as MIDI Mono Mode (and the foundation for modern MIDI Polyphonic Expression, or MPE).

In this configuration:

  • String 1 (High E) is mapped to MIDI Channel 1.
  • String 2 (B) is mapped to MIDI Channel 2.
  • String 3 (G) is mapped to MIDI Channel 3.
  • String 4 (D) is mapped to MIDI Channel 4.
  • String 5 (A) is mapped to MIDI Channel 5.
  • String 6 (Low E) is mapped to MIDI Channel 6.

Executing Independent String Bends

When a guitarist plays an oblique bend—fretting and holding the G string while bending the B string up a full tone—the system handles the execution through channel separation:

  1. Base Notes: The converter sends a Note On event on Channel 3 for the G string and another Note On event on Channel 2 for the B string.
  2. Dynamic Bend Tracking: As the B string is bent, the DSP detects the smooth increase in fundamental frequency.
  3. Targeted Pitch Bend Data: The converter outputs a stream of high-resolution continuous MIDI Pitch Bend commands exclusively on Channel 2.
  4. Target Response: The receiving synthesizer allocates separate sound engine voices to Channel 2 and Channel 3. Channel 2 alters its pitch upward in direct response to the incoming pitch data, while Channel 3 remains stationary at zero bend.

By isolating the physical string at the source and segregating the data stream into discrete channels, hexaphonic systems allow guitarists to maintain standard playing techniques—including pedal steel-style bends, finger vibrato on single notes inside a chord, and multi-string counterpoint—within a MIDI environment.
