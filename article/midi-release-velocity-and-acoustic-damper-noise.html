MIDI Release Velocity and Acoustic Damper Noise

MIDI release velocity is a specialized performance parameter that measures how fast a key returns to its resting position after being played. While standard MIDI velocity dictates how hard a note is struck, release velocity captures the nuance of the note's end, allowing virtual instruments to recreate the complex mechanical interactions of acoustic instruments. In acoustic pianos, the speed of key release directly affects how the felt dampers contact the vibrating strings, creating distinct acoustic artifacts. This article explores what MIDI release velocity is, how physical dampers interact with strings, and how modern virtual instruments utilize this data to dynamically synthesize authentic damper noise and release resonance.

Understanding MIDI Release Velocity

In the standard MIDI specification, every note event consists of a "Note On" message and a "Note Off" message. While almost all MIDI controllers transmit a "Note On" velocity value (ranging from 1 to 127) to indicate attack speed, many advanced controllers also transmit a velocity value with the "Note Off" message. This is known as MIDI Release Velocity or Note Off Velocity.

Release velocity measures the physical speed at which a key is released:

  • High release velocity (e.g., 90–127): The key is snapped or released abruptly.
  • Low release velocity (e.g., 1–40): The key is lifted slowly and gently.

Without release velocity support, virtual instruments must assume a static release speed (often fixed at a default value of 64), resulting in identical release artifacts regardless of the player's touch.

The Physical Mechanics of Acoustic Piano Dampers

To understand why release velocity matters in digital modeling, one must look at the mechanics of an acoustic piano.

Resting on top of—or alongside—the strings of an acoustic piano are felt-covered wooden wedges known as dampers. When a pianist presses a key, the corresponding damper lifts off the string, allowing it to vibrate freely. When the key is released, gravity (in a grand piano) or spring tension (in an upright) forces the damper back down onto the string to stop the vibration.

The speed of the key release fundamentally alters the sound of this termination:

  1. Fast Key Release: When a key is released quickly, the damper strikes the vibrating string with sudden force. This produces an audible, low-frequency mechanical "thud" as the felt hits the metal, along with the sound of the key mechanism and action parts settling into their resting positions. The sound terminates immediately with an abrupt acoustic cutoff.
  2. Slow Key Release: When a key is released slowly, the felt grazes the vibrating string before fully choking it. This creates a subtle friction noise—often heard as a brief, high-frequency buzzing or harmonic scrape—as the string’s energy is gradually dissipated. The mechanical noise of the action is virtually silent, and the tone dies out smoothly rather than cutting off sharply.

How Virtual Instruments Modulate Damper Noise

Modern virtual piano instruments and sample libraries use MIDI release velocity to replicate these acoustic nuances through dynamic sample selection and real-time DSP adjustments.

Dynamic Release Sample Triggering

High-end virtual pianos contain dedicated libraries of release samples recorded at multiple velocities. When a Note Off message is received:

  • A fast release triggers a sample with pronounced mechanical action noise, an audible damper-to-string thud, and prominent soundboard resonance caused by the sudden energy transfer.
  • A slow release triggers a quieter, softer sample that captures the gentle friction of felt touching wire with minimal action noise.

Release Envelope Scaling

In addition to triggering specific samples, synthesis engines and samplers use release velocity to scale the release stage of the amplitude envelope (ADSR):

  • High release velocity: Shortens the release time (\(T_{rel}\)), cutting the sustained note off instantaneously.
  • Low release velocity: Lengthens the release time, simulating the gradual decay caused by a softly descending damper.

High-Frequency Damping Filters

Some physically modeled instruments adjust cutoff filters dynamically upon key release. A slow key lift momentarily opens a bandpass or high-shelf filter to synthesize the characteristic string sizzle as the damper lightly touches the top of the string waveform before full closure.

Musical Importance of Release Velocity

Implementing release velocity removes the sterile, uniform sound common to basic digital keyboards. Legato phrasing, staccato passages, and expressive ballad playing rely heavily on release nuances. By translating key release speed into appropriate acoustic damper noise and release duration, digital instruments achieve the dynamic authenticity and physical presence required for realistic piano simulation.
