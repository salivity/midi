Calibrate Expression Pedal on MIDI Keyboard

Expression pedal calibration is an onboard firmware routine in a MIDI keyboard that maps the physical travel limits of an external pedal to the standard 0–127 MIDI control change (CC) value range. Because different pedal manufacturers use varying potentiometer resistances and mechanical sweep angles, keyboards rely on this procedure to establish precise heel-down (minimum) and toe-down (maximum) thresholds. The following guide explains how this internal calibration process functions and how to execute it on your controller.

The Internal Calibration Procedure: ADC Mapping

Inside the MIDI keyboard, the calibration process is technically known as Analog-to-Digital Converter (ADC) Range Calibration or simply Pedal Calibration.

Expression pedals operate as passive voltage dividers using a potentiometer. The keyboard supplies a small reference voltage (typically 3.3V or 5V) through the Tip-Ring-Sleeve (TRS) jack. As the pedal moves, the potentiometer varies the returned voltage read by the keyboard's internal ADC.

Because mechanical gears and pedal housings rarely utilize the entire electrical sweep of a potentiometer, the returned voltage rarely reaches absolute zero or absolute maximum. The calibration procedure solves this by:

  1. Sampling the Minimum Voltage: Registering the electrical output when the pedal is physically rested fully backward (heel-down) and setting this baseline voltage as MIDI CC value 0.
  2. Sampling the Maximum Voltage: Registering the electrical output when the pedal is pressed fully forward (toe-down) and setting this upper voltage limit as MIDI CC value 127.
  3. Establishing the Scaling Curve: Rescaling the ADC readings between these two defined extremes linearly (or logarithmically, depending on configuration), preventing dead zones at the start or end of the pedal's physical travel.

How to Perform the Calibration

While specific menu navigation varies by manufacturer, the standard procedure follows these steps:

  1. Connect the Pedal: Plug the TRS expression pedal into the designated EXPR or PEDAL input while the keyboard is powered on.
  2. Access System Setup: Navigate to the keyboard’s Global, System, or Pedal Setup menu via the onboard screen or dedicated control software.
  3. Select Pedal Calibration: Locate the parameter labeled Pedal Calibrate, Pedal Range, or Auto-Detect.
  4. Capture the Extremes:
    • When prompted, pull the pedal all the way back to the heel-down position and confirm the setting (stores the minimum value).
    • Push the pedal completely forward to the toe-down position and confirm the setting (stores the maximum value).
    • Some modern controllers only require you to sweep the pedal fully forward and backward once while the routine is active to auto-sense the voltage extremes.
  5. Set Polarity (If Necessary): If moving the pedal forward decreases the MIDI value instead of increasing it, toggle the pedal polarity setting within the same menu to invert the voltage sweep.
  6. Save to Memory: Save the global settings to persist the calibration data across power cycles.
