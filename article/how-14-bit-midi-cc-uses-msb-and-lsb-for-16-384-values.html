How 14-Bit MIDI CC Uses MSB and LSB for 16,384 Values

Standard MIDI Continuous Controller (CC) messages are limited to 128 steps, which often causes noticeable stepping or "zipper noise" during smooth parameter sweeps. To solve this, the MIDI specification allows two 7-bit CC messages to be paired together as a Most Significant Byte (MSB) and a Least Significant Byte (LSB). By combining these two streams into a single 14-bit data value, MIDI systems expand controller resolution from 128 to 16,384 distinct values, enabling high-precision control over parameters like filter cutoffs, pitch, and volume.

The 7-Bit Limitation in MIDI

In the MIDI 1.0 protocol, all standard data bytes are limited to 7 bits of usable data (values from 0 to 127). The eighth bit (the most significant bit) is reserved exclusively as an identifier flag to distinguish status bytes (commands) from data bytes. Because a single CC data byte can only represent \(2^7\) values, fine adjustments over a wide range inevitably result in coarse steps.

Pairing MSB and LSB

To achieve 14-bit resolution, MIDI pairs two distinct CC numbers to represent one continuous parameter:

  • MSB (Most Significant Byte / Coarse Control): Handles large parameter movements, effectively dividing the entire parameter range into 128 macro-segments.
  • LSB (Least Significant Byte / Fine Control): Handles micro-adjustments, dividing each of the 128 macro-segments into 128 sub-steps.

The MIDI standard pre-allocates CC numbers 0 through 31 as the MSB controls, and CC numbers 32 through 63 as their corresponding LSB partners. For example, CC 1 (Modulation Wheel MSB) pairs directly with CC 33 (Modulation Wheel LSB), and CC 7 (Volume MSB) pairs with CC 39 (Volume LSB). The LSB controller number is always the MSB controller number plus 32.

The Mathematics of 16,384 Values

When a MIDI receiver supports 14-bit CC, it does not treat the two received bytes independently; it stitches them together mathematically into a single 14-bit integer.

Because each byte carries 7 bits, joining them yields a total of 14 bits:

\[2^{14} = 16,384 \text{ total states (ranging from 0 to 16,383)}\]

To calculate the combined 14-bit value from the incoming data, the receiver bit-shifts the MSB to the left by 7 bits (equivalent to multiplying by 128) and adds the LSB value:

\[\text{Total Value} = (\text{MSB} \times 128) + \text{LSB}\]

Alternatively, expressed in bitwise operations:

\[\text{Total Value} = (\text{MSB} \ll 7) \mid \text{LSB}\]

Practical Example

  1. Minimum Value (0): Both MSB and LSB are set to 0. \[(0 \times 128) + 0 = 0\]
  2. Center Point (8,192): The MSB is set to 64, and the LSB is set to 0. \[(64 \times 128) + 0 = 8,192\]
  3. Maximum Value (16,383): Both MSB and LSB are set to their maximum 7-bit value of 127. \[(127 \times 128) + 127 = 16,383\]

Transmission and Processing

When a hardware knob or fader configured for 14-bit sends data, it transmits two separate MIDI messages. If a rapid, broad sweep occurs, the device might send updates primarily to the MSB. If a very slow, delicate adjustment occurs, only the LSB messages may be transmitted to adjust between the current macro-steps. A 14-bit compatible synthesizer or digital audio workstation (DAW) listens to both streams on the paired channels, instantly recalculating the 14-bit target position and eliminating audible stepping artifacts.
