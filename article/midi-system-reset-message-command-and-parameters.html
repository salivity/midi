MIDI System Reset Message Command and Parameters

The MIDI System Reset message is a global real-time command used to restore connected MIDI receivers to their initial power-up condition. This article outlines the specific byte value that defines the System Reset message, explains its role within the MIDI protocol, and details the precise parameters, operational states, and controller settings that it clears across receiving devices.

The MIDI System Reset Command

The MIDI System Reset command is defined by the single byte value 0xFF in hexadecimal (binary 11111111, or decimal 255).

Because it carries a status byte with no required data bytes, it is classified as a System Real-Time message. As a real-time message, it can be transmitted at any point in the MIDI data stream, even between the status and data bytes of other MIDI commands, without interrupting or corrupting the surrounding data structure.

Parameters Cleared by System Reset

When a receiving MIDI device processes an 0xFF message, it is instructed to return all functions to the state they were in when the device was first powered on. This initiates the clearing and reinitialization of several operational parameters:

  • Active Notes and Voices: All active sounding voices and held notes are silenced immediately, functioning as an emergency all-notes-off command.
  • Running Status: The receiver clears its Running Status buffer. The next channel or system message sent must include its full status byte to be recognized.
  • Continuous Controllers: Modulation wheels, breath controllers, expression pedals, and other continuous control parameters are reset to zero or their respective power-on neutral defaults.
  • Pitch Bend: The pitch bend value is reset to its centered, zero-offset resting position (value 8192 / center byte pair).
  • Switches and Pedals: Sustain (hold pedal), sostenuto, and soft pedal parameters are disengaged and turned off (value set to 0).
  • MIDI Operating Mode: The receiver reverts to its factory or user-configured default MIDI mode (commonly Omni On / Poly).
  • Channel Assignments: Receivers return to their default base reception channels.
  • Active Sensing: Active Sensing monitoring is terminated and reset until a new Active Sensing byte (0xFE) is detected.

The System Reset command does not erase permanent user memory, such as stored presets, saved sample data, or custom user patches stored in non-volatile RAM or flash storage. Its scope is strictly confined to dynamic operational states and playback parameters.
