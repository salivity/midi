Eurorack MIDI Polyphonic Voice Allocation Explained

Modern Eurorack MIDI-to-CV interfaces translate polyphonic MIDI data into four discrete pairs of Control Voltage (CV) and Gate outputs using embedded microcontrollers, precision digital-to-analog converters (DACs), and specialized voice allocation algorithms. By actively tracking incoming MIDI Note-On and Note-Off events in a voice registry, the module determines which physical CV/Gate output channel receives the 1V/Octave pitch and gate trigger for each note played. This article explains the internal mechanics of polyphonic voice allocation, including assignment modes, voice-stealing logic, and hardware signal conversion across a four-voice modular setup.

The Voice Registry and Note Tracking

At the core of a four-voice MIDI interface is an internal software array known as the voice registry. When a MIDI message arrives over DIN, TRS, or USB, the onboard microcontroller parses the status byte.

If a Note-On event occurs, the processor evaluates the four hardware voice channels to check their current status: active, releasing, or idle. The interface tracks note numbers (0–127), velocity values, and the precise timestamp of when each note was triggered. When a Note-Off message arrives, the module updates the corresponding channel's gate to 0V while maintaining the pitch CV at its last known value to prevent pitch-drop during the release phase of analog envelopes.

Allocation Modes

Modules typically provide several allocation algorithms to determine how incoming notes are distributed among the four outputs:

  • Round-Robin (Cyclic): Incoming notes cycle sequentially through channels 1, 2, 3, and 4. This mode distributes wear across analog modules and allows long release tails to ring out naturally without being cut off by subsequent notes.
  • Reset (Lowest Available): The interface always assigns the incoming note to the lowest-numbered inactive channel (e.g., Voice 1). This keeps polyphony concentrated on the primary voices, which is ideal if only some of your four analog voices share identical filter or envelope settings.
  • Random: Voices are assigned unpredictably across free channels, introducing subtle timbral variations when routing into slightly mismatched analog signal paths.
  • Unison/Monophonic Stack: All four CV/Gate pairs output the same note simultaneously, allowing you to trigger a massive four-oscillator mono patch with detuning.

Voice-Stealing Priorities

Because modular synthesizers have a finite number of physical voices—in this case, four—the interface must handle polyphonic overflow when a musician plays a fifth note. Voice-stealing algorithms decide which active note to terminate:

  • Oldest Note (First-In, First-Out): The channel holding the note that was triggered earliest is interrupted and reassigned to the newest note. This is the most common and musically transparent approach for keyboard playing.
  • Lowest / Highest Note Priority: The interface preserves the extreme ends of the frequency spectrum (often the bass note or the lead melody) and steals voices strictly from the middle of the chord.
  • Re-triggering Matching Notes: If a newly played note matches a note already ringing out on one of the channels, the module prioritizes re-allocating that specific channel rather than stealing a different pitch.

Digital-to-Analog Signal Generation

Once the microcontroller assigns a note to a specific voice channel, it calculates the corresponding voltage using the standard 1V/Octave scale (1/12th of a volt per semitone).

  1. Pitch CV: The digital pitch value is transmitted via high-speed SPI or I2C to a multi-channel, high-resolution DAC (typically 12-bit to 16-bit). Operational amplifiers buffer and calibrate this signal to ensure pitch tracking remains accurate across multiple octaves.
  2. Gate Output: Simultaneously, a digital GPIO pin on the microcontroller shifts high, sending a 5V or 10V pulse to the corresponding Gate output jack to trigger external envelope generators.
  3. Auxiliary CV (Velocity/Aftertouch): Advanced quad interfaces also assign secondary DAC channels to output per-voice velocity or polyphonic aftertouch alongside the standard CV/Gate pair, giving each of the four voices independent expressive dynamics.
