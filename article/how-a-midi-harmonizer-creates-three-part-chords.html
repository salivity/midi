How a MIDI Harmonizer Creates Three-Part Chords

A hardware MIDI harmonizer transforms a single incoming root note into a full three-part chord through real-time data parsing, scale-based algorithmic processing, and multi-note generation. By interpreting the pitch of an incoming MIDI message, referencing user-defined musical parameters such as key and scale, and instantly generating the appropriate complementary intervals, the device outputs a coordinated set of notes that form a harmonically accurate triad with near-zero latency.

1. Receiving and Parsing the Input Message

The process begins at the hardware’s physical MIDI IN port (or USB-MIDI interface). When a musician plays a key, the controller transmits an asynchronous serial digital signal. The harmonizer’s microprocessor monitors this stream and immediately captures the standard three-byte Note On command:

  • Byte 1 (Status Byte): Indicates the command type (Note On) and the specific MIDI channel.
  • Byte 2 (Data Byte 1): Represents the pitch value as a number from 0 to 127 (for example, Middle C is 60).
  • Byte 3 (Data Byte 2): Captures the strike velocity (0 to 127), which represents volume and dynamics.

2. Musical Context and Lookup Tables

Unlike a basic pitch shifter that adds fixed intervals (such as always adding 4 semitones), an intelligent MIDI harmonizer relies on musical context. The user presets a musical key (e.g., G) and a scale type (e.g., Major, Natural Minor, Mixolydian). Alternatively, some devices determine the context dynamically via a secondary MIDI input receiving chord data from an accompanying instrument.

Internally, the harmonizer holds pre-programmed lookup tables that define the allowable scale degrees for every key. When the incoming note arrives, the processor cross-references the note number against the active scale to determine its diatonic role (e.g., tonic, mediant, dominant).

3. Calculating the Harmony Notes

To build a standard three-part chord, the unit needs to calculate two additional pitches alongside the root—typically the 3rd and the 5th degree above the root note within the selected scale:

  • Diad Calculation: If the input is C (MIDI note 60) in the key of C Major, the harmonizer looks up the third scale degree above it (E, MIDI note 64) and the fifth scale degree (G, MIDI note 67).
  • Dynamic Interval Adjustment: If the next input note is D (MIDI note 62), the harmonizer’s logic knows that a major third would produce an out-of-key F# (66). Instead, it automatically selects a minor third (F, MIDI note 65) and a perfect fifth (A, MIDI note 69) to maintain strict diatonic harmony.

Advanced hardware units also feature voice-leading algorithms that apply inversions or octave shifts to prevent harmony voices from jumping erratically across high or low frequency registers.

4. Velocity and Timing Processing

To ensure the resulting chord sounds natural, the hardware assigns appropriate velocity values to the newly calculated notes. Typically, the harmonizer duplicates the velocity of the original root note across all voices, though many units permit scaling (e.g., setting harmony voices to play slightly softer than the lead note).

The processor also handles the timing envelope. When the input key is released, the device captures the corresponding Note Off message for the root note and instantly transmits matching Note Off commands for the harmony voices to prevent stuck notes.

5. Generating the Multi-Voice Output

Once the processor calculates the target pitches, it constructs two new Note On messages. The hardware serializes these messages and transmits all three notes (the original root plus the two generated harmonies) through the MIDI OUT port in rapid succession. Because standard 5-pin DIN MIDI runs at 31.25 kbaud, sending three consecutive three-byte messages takes under one millisecond, ensuring the human ear perceives the three notes as a simultaneous, three-part chord.
