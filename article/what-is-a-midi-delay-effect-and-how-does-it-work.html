What Is a MIDI Delay Effect and How Does It Work?

A MIDI delay effect is an event-based processor that manipulates digital performance data rather than recorded audio waveforms to produce rhythmic repetitions. Unlike traditional audio delays that manipulate and repeat an existing audio signal, a MIDI delay duplicates the musical instructions sent to a synthesizer or sampler. This article explains what a MIDI delay is, how it differs from an audio delay, and the algorithmic process it uses to generate repeating Note On messages with decaying velocity values.

Defining the MIDI Delay

A MIDI delay operates strictly within the MIDI protocol domain. When a musician plays a note on a keyboard, the instrument generates data packets containing information such as pitch, channel, and velocity. A MIDI delay intercepts these data packets, holds them in a buffer, and outputs duplicates at specified time intervals.

Because the delay occurs before sound generation, each repetition triggers the target sound engine anew. This allows subsequent repeats to trigger new synthesizer envelope cycles, distinct round-robin sample layers, and dynamic filter responses, resulting in a cleaner and more modular performance than traditional audio echoes.

How Repeating Note On Messages Are Generated

The generation of repeating notes relies on a clock-synchronized or millisecond-based timing loop. The process unfolds in several precise steps:

  1. Message Interception: When a key is pressed, the MIDI delay receives a Note On message containing the note number (pitch) and an initial velocity value (ranging from 1 to 127).
  2. Time Calculation: The processor reads its timing parameters—either set to absolute milliseconds or synchronized to musical divisions (such as 1/8 notes or 1/16 notes based on the host tempo). It calculates the target timestamp for when the first repetition should occur.
  3. Queueing and Re-transmission: The system places the note event into a scheduling buffer. Once the internal clock reaches the calculated timestamp, the processor transmits a new Note On message with the identical note number to the destination sound generator.
  4. Note Off Pairing: To maintain proper articulation and prevent hanging notes, the processor also tracks the original Note Off message (or note duration) and generates corresponding Note Off messages for every delayed iteration.

The Velocity Decay Mechanism

In an audio delay, repetitions fade out because the amplitude of the audio waveform is reduced through a feedback circuit. In a MIDI delay, volume attenuation is achieved mathematically by lowering the velocity parameter of each successive Note On event.

The Feedback Calculation

The reduction in velocity is controlled by a feedback or decay setting within the effect's algorithm. This is calculated using either a multiplicative scaling factor or a fixed subtraction method:

  • Multiplicative Scaling: The algorithm multiplies the previous velocity by a decay coefficient (e.g., \(Velocity_{next} = Velocity_{current} \times 0.75\)). This creates an exponential decay that closely mimics acoustic energy dissipation.
  • Fixed Subtraction: The algorithm subtracts a constant integer value on each cycle (e.g., \(Velocity_{next} = Velocity_{current} - 15\)). This yields a linear decay rate.

Cutoff and Termination

MIDI velocity values are strictly limited to integers between 0 and 127, where a velocity of 0 is functionally interpreted as a Note Off command.

During each repetition cycle, the processor calculates the new velocity value and checks it against a minimum threshold:

  • If the newly calculated velocity is greater than zero (or a user-defined threshold, such as 1), the processor rounds the value to the nearest integer and schedules the new Note On event.
  • Once the mathematical decay causes the velocity value to reach zero or fall below the minimum threshold, the algorithm stops generating repetitions for that note event and clears it from the buffer.

Through this digital feedback loop, the MIDI delay continuously outputs distinct, progressively softer performance instructions that cause the target instrument to play the musical phrase until it naturally fades away.
