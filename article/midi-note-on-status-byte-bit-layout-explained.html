MIDI Note On Status Byte Bit Layout Explained

This article breaks down the exact 8-bit structure of the standard MIDI Note On status byte, explaining how the message identifier and channel number combine at the binary level. It outlines the foundational binary rules governing MIDI channel voice messages and provides a comprehensive reference table showing the precise bit layout, binary value, and hexadecimal equivalent across all sixteen addressable MIDI channels.

Binary Structure of the Note On Status Byte

A standard MIDI status byte is an 8-bit word (one byte) distinguished by a Most Significant Bit (MSB, Bit 7) permanently set to 1. In contrast, MIDI data bytes always have an MSB of 0.

The Note On status byte follows a strict two-nibble architecture represented as 1001cccc:

  • Bits 7–4 (Upper Nibble): Fixed as 1001 (Hexadecimal 9). This represents the Note On command identifier.
  • Bits 3–0 (Lower Nibble): Represented as cccc. This 4-bit field designates the target MIDI channel using zero-indexed binary encoding (0 to 15), corresponding to user-facing Channels 1 through 16.
