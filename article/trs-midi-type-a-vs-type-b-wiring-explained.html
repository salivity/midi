TRS MIDI Type A vs Type B Wiring Explained

TRS MIDI allows compact audio gear to transmit standard serial MIDI data over 3.5mm or 1/4-inch audio cables instead of bulky 5-pin DIN connectors. Before the MIDI Association established an official specification, hardware manufacturers split into two competing implementations: Type A and Type B. While both standards keep the electrical ground on the sleeve, they reverse the functional roles of the tip and ring conductors. This guide explains how this signal swap works and why the reversal prevents devices of different standards from communicating directly.

The 5-Pin DIN Origin

A traditional 5-pin DIN MIDI cable uses only three pins for communication:

  • Pin 4: Current source (Positive/Pull-up voltage, typically 3.3V or 5V through a resistor).
  • Pin 5: Current sink (Data line, pulled low to transmit binary data).
  • Pin 2: Ground (Shield).
  • Pins 1 and 3: Unconnected.

When transferring these connections to a 3-conductor TRS (Tip-Ring-Sleeve) plug, the shield connects to the sleeve in both Type A and Type B formats. The difference lies exclusively in which pin connects to the tip and which connects to the ring.

Type A Wiring Configuration

The MIDI Association officially adopted Type A as the universal standard (defined in specification RP-054). In Type A:

  • Tip: Connects to Pin 5 (Data / Current sink).
  • Ring: Connects to Pin 4 (Voltage / Current source).
  • Sleeve: Connects to Pin 2 (Ground / Shield).

Brands such as Korg, Roland, Make Noise, and newer Akai models use this configuration.

Type B Wiring Configuration

Before the official standard was defined, manufacturers like Arturia, Novation, and 1010music implemented Type B. In Type B:

  • Tip: Connects to Pin 4 (Voltage / Current source).
  • Ring: Connects to Pin 5 (Data / Current sink).
  • Sleeve: Connects to Pin 2 (Ground / Shield).

How the Signal Path Is Reversed

The reversal is a 180-degree swap of the active conductors:

Connection Type A Assignment Type B Assignment
Tip Pin 5 (Data / Sink) Pin 4 (Source / Voltage)
Ring Pin 4 (Source / Voltage) Pin 5 (Data / Sink)
Sleeve Pin 2 (Ground / Shield) Pin 2 (Ground / Shield)

At an electrical level, MIDI relies on a current loop to activate an optocoupler inside the receiving device. Current flows out of the transmitter via Pin 4, passes through the receiver's optocoupler LED, and returns through Pin 5 when the data line pulls low.

When a Type A output connects directly to a Type B input via a standard stereo TRS cable, the transmitter's voltage source (Ring) is routed directly into the receiver's data sink, and the transmitter's data line (Tip) aligns with the receiver's voltage input. This inverts the polarity across the receiver's optocoupler. Because LEDs only conduct current in one direction, the reversed polarity prevents the optocoupler from illuminating, causing the receiving device to register no data.

To bridge a Type A device and a Type B device, a crossover cable or adapter is required to physically swap the wires connected to the tip and the ring while keeping the sleeve grounded.
