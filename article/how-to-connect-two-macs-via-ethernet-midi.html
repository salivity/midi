How to Connect Two Macs via Ethernet MIDI

This guide details the process of connecting two Mac computers to transmit low-latency MIDI data over a local Ethernet connection. Using macOS's built-in CoreMIDI network functionality within the Audio MIDI Setup utility, you can reliably send note data, clock synchronization, and continuous controllers between digital audio workstations (DAWs) on separate machines without needing third-party software or specialized MIDI interfaces.

1. Establish the Physical Network Connection

  1. Connect both Macs using an Ethernet cable (either directly from port to port, or through a gigabit Ethernet switch/router).
  2. On both computers, go to System Settings > Network > Ethernet and ensure both machines have valid IP addresses on the same local subnet.

2. Open the MIDI Studio

Perform these steps on both Macs:

  1. Open Finder and navigate to Applications > Utilities > Audio MIDI Setup.
  2. If the MIDI Studio window is not visible, select Window > Show MIDI Studio (or press Command + 2).
  3. Click the Network icon (represented by a globe or network port) in the MIDI Studio toolbar to open the MIDI Network Setup window.

3. Create and Configure a Session on the First Mac

On the first Mac (Mac A):

  1. In the My Sessions panel in the upper-left, click the + (plus) button to create a new session.
  2. Check the box next to the newly created session to enable it.
  3. In the right-hand panel, set both the Session Name (e.g., Mac A Studio) and the Bonjour Name (e.g., Mac A).
  4. At the bottom of the window, locate the Who may connect to me: drop-down menu and select Anyone.

4. Create and Configure a Session on the Second Mac

On the second Mac (Mac B):

  1. Follow the same procedure: click the + button under My Sessions and check the box to enable it.
  2. Name the session and Bonjour identifier (e.g., Mac B Studio and Mac B).
  3. Set Who may connect to me: to Anyone.

5. Pair the Two Machines

  1. In the Directory pane on either Mac, wait a few seconds for the Bonjour service to discover the other machine's session name.
  2. Select the remote Mac’s session name in the Directory list.
  3. Click the Connect button beneath the Directory list.
  4. The remote session name will move into the Participants list on both computers, confirming an active, bidirectional MIDI link.

6. Verify and Route MIDI in Your DAW

Once the connection is established, the network session appears as a standard MIDI input and output port in your DAW (such as Logic Pro, Ableton Live, or Pro Tools). Set your sending track's MIDI output to the Network Session port on the transmitting Mac, and set your receiving track's MIDI input to the corresponding Network Session port on the destination Mac.
