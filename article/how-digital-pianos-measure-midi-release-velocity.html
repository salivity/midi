How Digital Pianos Measure MIDI Release Velocity

Digital pianos achieve nuanced acoustic realism by capturing both how hard a key is struck and how quickly it is released. While basic keyboards transmit a static value upon key release, advanced digital pianos measure and send two separate MIDI velocity values: Note-On velocity and Note-Off (release) velocity. This article explains the hardware sensor mechanics and the MIDI communication protocol that allow an instrument to detect upward key speed and translate it into expressive performance data.

The Standard MIDI Velocity Messages

Every standard MIDI note event consists of status and data bytes. To capture key dynamics accurately, the MIDI standard defines two distinct event types:

  1. Note-On Message (0x90): Sent when a key is pressed. It contains the pitch and a strike velocity value (1–127) determining the volume and initial timbre.
  2. Note-Off Message (0x80): Sent when a key is released. While basic controllers often substitute this with a Note-On command with a velocity of 0, instruments supporting release velocity transmit a true Note-Off status byte followed by the note number and a variable release velocity value (0–127).

By utilizing dedicated Note-Off velocity bytes, the piano communicates key-return speed without altering the initial strike data.

Hardware Sensor Configuration

Measuring key travel in both directions requires physical switch points beneath each key. Standard keyboards rely on two rubber dome or optical sensors, while high-performance digital pianos use a three-sensor configuration.

  • Sensor 1 (Top/Rest position): Located near the resting state of the key.
  • Sensor 2 (Midpoint): Positioned along the key travel path.
  • Sensor 3 (Bottom/Bed position): Located at the point of full key depression.

When a pianist presses a key down, an internal micro-controller measures the elapsed time between the key triggering Sensor 1 and Sensor 2 (or Sensor 2 and Sensor 3). A shorter elapsed time corresponds to a higher Note-On velocity value.

Calculating Release Speed

To register release speed, the sensor activation sequence is reversed during the upward key return:

  1. Upward Motion Detection: As the player lifts their finger, the key begins its upward travel, leaving Sensor 3 and returning past Sensor 2 and Sensor 1.
  2. Time-to-Velocity Measurement: The internal processor starts a timer the instant the key breaks contact with the lower sensor and stops the timer when it passes the middle or upper sensor.
  3. Value Mapping: The microcontroller calculates the velocity (\(v = \text{distance} / \text{time}\)) of the upward stroke. This value is mapped along an algorithmic curve into a standard 7-bit integer range (1–127).
  4. Packet Dispatch: The system packages this integer into the third byte of a 0x80 (Note-Off) MIDI message and sends it via the MIDI or USB output.

Sound Engine Implementation

Virtual instruments and onboard sound engines interpret the Note-Off velocity value to modify the release phase of the sound envelope. A slow release (low velocity) models a damper gently lowering onto vibrating piano strings, producing a smooth, lingering decay. A rapid release (high velocity) immediately cuts the sound and triggers mechanical damper-thud samples, mirroring the abrupt physical dampening of an acoustic grand piano.
