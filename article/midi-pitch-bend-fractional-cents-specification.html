MIDI Pitch Bend Fractional Cents Specification

This article explores how the MIDI specification handles fractional microtonal cents using standard pitch bend messages. It details the 14-bit data architecture of pitch bend events, explains how pitch bend sensitivity dictates cent resolution, demonstrates the mathematics for calculating fractional cent values, and clarifies the boundaries between standard pitch bend operations and dedicated microtuning protocols.

14-Bit Pitch Bend Architecture

Standard MIDI pitch bend is transmitted using a dedicated channel voice message consisting of a status byte (0xEn, where n represents the zero-indexed channel) followed by two 7-bit data bytes: the Least Significant Byte (LSB) and the Most Significant Byte (MSB).

Combining these two 7-bit bytes yields a 14-bit unsigned integer ranging from 0 to 16,383:

  • 0 (0x00 0x00): Maximum negative bend
  • 8,192 (0x00 0x40): Center / No pitch bend (neutral pitch)
  • 16,383 (0x7F 0x7F): Maximum positive bend

The MIDI specification does not transmit fractional cents directly as an absolute unit within the message. Instead, the 14-bit value represents an abstract offset from the center value (8,192), which the receiving synthesizer scales according to its Pitch Bend Sensitivity parameter.

Pitch Bend Sensitivity and Resolution

Pitch Bend Sensitivity is configured via Registered Parameter Number (RPN) 0 (RPN 00 00). This parameter defines the maximum semitone and cent deviation applied when the pitch bend wheel reaches its extreme limits. The default sensitivity in General MIDI is ±2 semitones (±200 cents).

Because there are 8,191 discrete steps between the center (8,192) and the maximum value (16,383), the resolution per step is determined by the total range configured in cents:

\[\text{Cents per Step} = \frac{\text{Bend Range in Cents}}{8192}\]

For the standard default range of ±200 cents:

\[\frac{200 \text{ cents}}{8192 \text{ steps}} \approx 0.024414 \text{ cents per step}\]

Because 0.0244 cents is far below the human pitch discrimination threshold (the Just Noticeable Difference for pitch is roughly 5 to 6 cents under standard conditions), standard 14-bit pitch bend inherently provides sub-cent microtonal precision.

Calculating Fractional Cent Offsets

To transmit a specific fractional cent offset, the target deviation must be mapped to a 14-bit value relative to the 8,192 baseline.

  1. Determine the desired cent offset (\(\Delta C\)): For example, a quarter-tone sharp requires \(+50.0\) cents.
  2. Calculate the normalized bend step: \[\text{Bend Value} = 8192 + \left( \frac{\Delta C}{\text{Max Bend Range in Cents}} \times 8191 \right)\] For \(+50\) cents within a \(\pm 200\)-cent range: \[\text{Bend Value} = 8192 + \left( \frac{50}{200} \times 8191 \right) = 8192 + 2047.75 \approx 10240\]
  3. Split into LSB and MSB: \[\text{LSB} = \text{Bend Value} \pmod{128} = 10240 \pmod{128} = 0\] \[\text{MSB} = \lfloor \frac{\text{Bend Value}}{128} \rfloor = \lfloor \frac{10240}{128} \rfloor = 80 \text{ (or } 0x50 \text{)}\]

The resulting MIDI message transmits as 0xEn 0x00 0x50, achieving an accurate microtonal pitch without requiring proprietary protocols.

Practical Limitations in MIDI 1.0

While the 14-bit resolution is mathematically sufficient to represent precise fractional cents, using pitch bend for microtonality in standard MIDI 1.0 has functional constraints:

  • Channel-Wide Scope: Standard pitch bend messages affect all active voices on the designated MIDI channel. Monophonic microtonal lines transmit accurately, but true polyphonic microtonality requires MIDI Polyphonic Expression (MPE) or assigning individual notes to separate MIDI channels.
  • Non-Standardized Defaults: If a receiving device has its pitch bend sensitivity altered away from the expected range, the calculated fractional cent values will produce inaccurate intervals.

For dynamic or static tuning adjustments that avoid pitch bend scaling entirely, the MIDI Tuning Standard (MTS) provides dedicated SysEx and Non-Registered Parameter commands to define frequency representations to an exact precision of \(0.0061\) cents per key. In MIDI 2.0, standard pitch bend resolution is expanded to 32-bit values and supports Per-Note Pitch Bend natively, resolving channel-wide limitations while offering fractional cent resolution far exceeding analog acoustic requirements.
