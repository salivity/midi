What Causes MIDI Filter Sweep Zipper Noise?

Zipper noise occurs when sweeping an audio parameter, such as a filter's cutoff frequency, because standard 7-bit MIDI Control Change (CC) messages lack the resolution needed for smooth, continuous adjustments. Instead of a fluid transition, the parameter jumps between a limited number of discrete values. These sudden, stepped updates create rapid micro-transients in the audio signal that sound distinctly like a zipper being pulled.

Low Value Resolution (7-Bit Quantization)

The primary driver of zipper noise is the mathematical limitation of standard MIDI. A standard MIDI CC message uses a 7-bit data byte, which allows for only 128 distinct values (from 0 to 127).

When you map these 128 values across a wide parameter range—such as a low-pass filter sweeping from 20 Hz to 20,000 Hz—each single increment represents a substantial leap in frequency. Even when mapped logarithmically to match human hearing, jumping from one value to the next causes an instantaneous step change in the filter's coefficients rather than a continuous slide.

Waveform Discontinuities

Digital filters process audio sample by sample. When a filter's cutoff frequency abruptly updates mid-stream, the filter's internal state variables and response characteristics instantly change.

This instantaneous recalculation creates a tiny discontinuity, or sudden jump in amplitude and phase, in the audio signal passing through the filter. When the control knob is turned quickly, the parameter steps through several values in rapid succession. The resulting sequence of clicks and pops blends together into a buzzing, high-frequency artifact known as zipper noise.

Temporal Density and Update Rate

Standard MIDI hardware runs at a baud rate of 31,250 bits per second. Even via modern USB connections, standard MIDI CC events are transmitted as distinct, isolated packets rather than a continuous control voltage.

If a synthesizer or digital audio workstation (DAW) applies each incoming MIDI value instantly upon arrival without internal smoothing, the parameter stays flat between messages and then jumps sharply when the next message arrives. This creates a staircase-shaped modulation signal.

Why Modern Systems Mitigate This

Zipper noise is primarily a symptom of unsmoothed control logic. Modern synthesizers and audio plugins prevent this artifact by applying parameter interpolation (slew limiting or low-pass filtering) directly to incoming MIDI CC data. Smoothing rounds off the harsh corners of the staircase waveform, creating a continuous ramp between the 128 discrete steps. Additionally, newer protocols like 14-bit MIDI (which provides 16,384 values) and MIDI 2.0 (with 32-bit resolution) virtually eliminate the issue at the protocol level.
