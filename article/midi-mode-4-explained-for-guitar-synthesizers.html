MIDI Mode 4 Explained for Guitar Synthesizers

MIDI Mode 4, designated as "Omni Off, Mono," is the essential configuration standard used by multi-channel guitar synthesizers to achieve accurate, independent polyphonic performance. By assigning each physical string of a guitar to its own dedicated, monophonic MIDI channel, Mode 4 enables independent pitch bending, modulation, and expressive control per string. This article explains the technical mechanics of Mode 4, why it is necessary for guitarists, and how it overcomes the expressive limitations of traditional MIDI modes.

The Technical Definition of MIDI Mode 4

MIDI specification defines four basic receiver modes based on two parameters: Omni state (On or Off) and voice allocation (Poly or Mono).

  • Omni Off: The receiving device listens only to designated, discrete MIDI channels rather than responding globally to data across all 16 channels.
  • Mono: Each channel is restricted to playing a single voice (note) at any given moment.

In Mode 4, a synthesizer or sound module is set up to act as multiple independent monophonic synthesizers operating in parallel across a consecutive block of MIDI channels.

The Limitation of Mode 3 (Omni Off, Poly)

In standard keyboard-centric setups, Mode 3 (Poly Mode) is the default. In this mode, multiple notes are transmitted simultaneously over a single MIDI channel.

While this works seamlessly for keyboards, it fails to capture guitar performance nuances. In the MIDI specification, control change messages and Pitch Bend messages are channel-wide instructions. If two notes are sustained on the same MIDI channel and a pitch bend message is sent, both notes are forced to bend simultaneously by the same interval.

On a guitar, a player frequently bends one string while holding another stationary (a pedal steel bend or unison bend). In Mode 3, doing so results in unnatural pitch warping of all sounding notes on that channel.

How Mode 4 Solves the Guitar Problem

Mode 4 solves this limitation by mirroring the physical design of the instrument:

  1. Per-String Channel Allocation: A hexaphonic (divided) pickup isolates the audio signal of each string. The pitch-to-MIDI converter then maps each string to a separate, consecutive MIDI channel (typically Channels 1 through 6 for a standard six-string guitar).
  2. Dedicated Pitch Bends: Because each string has its own channel, Pitch Bend messages generated by bending the B string are sent exclusively on that string's channel. The notes ringing out on other strings remain completely unaffected.
  3. Natural Monophonic Behavior: A single guitar string can physically only vibrate at one fundamental pitch at a time. The "Mono" component of Mode 4 reinforces this reality: playing a new note on the same string automatically issues a Note Off command for the previous note on that channel, preventing unintended polyphonic overlap.
  4. Independent Expression per String: Beyond pitch bends, each string can send discrete continuous controller data. Parameters such as brightness (filter cutoff), aftertouch, or volume can fluctuate dynamically based on how hard or dynamically an individual string is played.

Hardware and Sound Module Requirements

To take full advantage of Mode 4, the receiving synthesizer must support multi-timbral reception and allow voice allocation across multiple channels sharing identical patch parameters. Modern instruments often refer to this functionality under terms such as "Guitar Mode," "Multi-Mono," or within the broader framework of MPE (MIDI Polyphonic Expression), which builds on the architectural principles originally established by MIDI Mode 4.
