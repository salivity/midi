MIDI Set Tempo Meta Event Byte Sequence

Standard MIDI Files (SMF) use dedicated non-MIDI control sequences known as Meta Events to handle track metadata, time signatures, and playback tempo. This article identifies the specific byte sequence responsible for an instantaneous change in beats per minute (BPM), breaks down the function of each byte in the event, and explains the mathematical conversion between standard BPM and MIDI tempo values.

The Set Tempo Byte Sequence

An instantaneous tempo change in a MIDI file is defined by a six-byte Meta Event sequence:

FF 51 03 tt tt tt

Each component of this sequence serves a distinct function:

  • 0xFF (Status Byte): Denotes that the message is a MIDI Meta Event rather than a standard channel voice or system common message.
  • 0x51 (Type Byte): Specifies the "Set Tempo" meta event.
  • 0x03 (Length Byte): Indicates the length of the payload that follows, which is always exactly 3 bytes for a tempo event.
  • tt tt tt (Data Bytes): A 24-bit big-endian integer representing the tempo in microseconds per MIDI quarter-note (\(\mu\text{s/qn}\)).

Because this event is assigned a specific delta-time within a MIDI track chunk, the tempo switch takes effect immediately at that exact tick, instantaneously altering the project's playback speed.

Converting BPM to MIDI Microseconds

MIDI files do not store tempo directly as beats per minute. Instead, they store the duration of a single quarter note in microseconds (\(1\text{ second} = 1,000,000\text{ microseconds}\)).

To convert BPM into the 3-byte MIDI value:

\[\text{Microseconds per Quarter Note} = \frac{60,000,000}{\text{BPM}}\]

To calculate BPM from a MIDI tempo event:

\[\text{BPM} = \frac{60,000,000}{\text{Microseconds per Quarter Note}}\]

Concrete Example: 120 BPM

To set a project tempo to standard 120 BPM:

  1. Divide \(60,000,000\) by \(120\), which yields \(500,000\) microseconds per quarter note.
  2. Convert the decimal value \(500,000\) to a 3-byte hexadecimal value:
    • \(500,000_{10} = \text{0x07A120}\)
  3. Combine the prefix and the hex value into the complete sequence:
    • FF 51 03 07 A1 20

When a MIDI sequencer encounters FF 51 03 07 A1 20, it immediately sets the project tempo to 120 BPM at that point in the timeline.
