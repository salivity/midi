Serial Overhead of MIDI Note On and Note Off

An isolated, un-optimized standard MIDI Note On and Note Off message sequence transmits a total of 6 bytes over a serial connection, consuming exactly 2 bytes of protocol status overhead. At the physical UART serial layer, each 8-bit byte is encapsulated in 10 serial bits, contributing an additional 12 bits (equivalent to 1.5 bytes) of serial framing overhead across the entire 60-bit transmission.

Standard MIDI Message Breakdown

A standard MIDI 1.0 Note On and Note Off sequence without optimization (such as Running Status) consists of two distinct 3-byte Channel Voice messages:

  1. Note On Event (3 Bytes)
    • Byte 1 (Status): 0x9n (where n is the MIDI channel, 0–15)
    • Byte 2 (Data 1): Note number (0–127)
    • Byte 3 (Data 2): Velocity (1–127)
  2. Note Off Event (3 Bytes)
    • Byte 1 (Status): 0x8n (or 0x9n with a velocity of 0)
    • Byte 2 (Data 1): Note number (0–127)
    • Byte 3 (Data 2): Release velocity (0–127)

Byte-Level Protocol Overhead

In communications protocol design, "overhead" represents the non-payload control data required to route and identify the message.

  • Payload: The core musical data consists of the note pitch and velocity pairs (4 bytes total: 2 bytes for Note On, 2 bytes for Note Off).
  • Protocol Overhead: The status bytes (0x9n and 0x8n) act as the message identifiers. In an isolated sequence where Running Status cannot be applied, both status bytes must be explicitly sent.

This results in 2 bytes of protocol overhead out of the 6 total bytes transmitted (a 33.3% protocol overhead).

Physical Layer (UART) Serial Framing Overhead

Standard 5-pin DIN and serial MIDI operate asynchronously at a fixed rate of 31,250 baud using an 8-N-1 configuration:

  • 1 Start Bit
  • 8 Data Bits
  • No Parity
  • 1 Stop Bit

Because each 8-bit byte requires 10 physical bits on the wire, the physical serial layer adds 2 bits of framing overhead per byte:

  • Total Bits Transmitted: 6 bytes × 10 bits/byte = 60 bits
  • Actual MIDI Data Bits: 6 bytes × 8 bits/byte = 48 bits
  • Framing Overhead Bits: 6 bytes × 2 framing bits/byte = 12 bits

The physical framing consumes 12 bits of framing overhead, which equates to 1.5 bytes of additional transmission time on the serial line.
