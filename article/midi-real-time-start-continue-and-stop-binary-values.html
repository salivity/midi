MIDI Real-Time Start, Continue, and Stop Binary Values

This guide details the exact binary, hexadecimal, and decimal values that define MIDI System Real-Time Start, Continue, and Stop transport messages. These fundamental single-byte status commands allow sequencers, drum machines, and digital audio workstations (DAWs) to synchronize playback states instantly across interconnected hardware gear.

The MIDI Transport Command Values

MIDI System Real-Time messages are unique because they consist of a single status byte with no accompanying data bytes. They carry the highest priority in the MIDI specification and can be transmitted at any point in the data stream, even between the bytes of other multi-byte messages.

The three primary playback synchronization commands are defined as follows:

Command Binary Value Hexadecimal Decimal
Start 11111010 0xFA 250
Continue 11111011 0xFB 251
Stop 11111100 0xFC 252

Start (11111010 / 0xFA)

The Start command signals all synchronized receiving devices to begin playback immediately from the very beginning of the sequence (measure 1, beat 1, tick 0). Upon receiving this byte, slave devices reset their internal position pointers to zero and start processing incoming MIDI Clock pulses (11111000 or 0xF8).

Continue (11111011 / 0xFB)

The Continue command instructs receiving gear to resume playback from the exact location where playback was previously paused or stopped. It does not reset the internal song position pointer. When paired with MIDI Song Position Pointer (SPP) messages, a master device can cue a specific measure and then issue the 11111011 command to start playback from that specific measure instead of the beginning.

Stop (11111100 / 0xFC)

The Stop command halts playback immediately on all synchronized receiving devices. The internal position counter pauses at the current point in time, preserving the playback location so that a subsequent Continue command can resume playback from the same point.

Implementation Across Synchronized Setups

Because these commands are standard 8-bit status bytes starting with four high bits (1111), hardware receivers immediately identify them as Real-Time category events. When configuring master and slave hardware:

  • Master Devices: Transmit 0xFA, 0xFB, and 0xFC whenever the user triggers play, resume, or pause/stop controls, interspersed with the 24 PPQN (pulses per quarter note) MIDI Timing Clock (0xF8).
  • Slave Devices: Listen continuously for these values to latch transport states to the master device with zero processing latency.
